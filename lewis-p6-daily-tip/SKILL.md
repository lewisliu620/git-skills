# Lewis P6 WorkBuddy 每日技巧

> ## 🔴 第一原则（2026-11-01 固化，与 lewis-video-director / viral-video-topics 同源）
>
> **出 P6 脚本前必须先查「视频创作知识库」并按知识库爆款标准来写；出完必自检，合格才交付。查库是写稿的前置动作，不允许先写后查、更不允许不查就写。** 强制闭环：**①出稿前查库（先）→ ②按命中的知识库爆款标准出脚本（中）→ ③出稿后按自检清单核验（后），三步缺一不可。**
> 1. **出脚本前先查库**：拿到当日 P6 选题后、动笔写任何一镜之前，必须先按 `viral-video-topics/references/knowledge-base-check.md` 查「视频创作知识库」（选题/脚本结构/案例库：清单结构、钩子、带走物、平台规则等对应模块），用命中的知识库爆款标准决定钩子怎么写、结构怎么搭、带走物放哪，命中卡标注 card_id + 来源 + 采集日期；有【对标】案例卡时先参考再出稿；检索不到标注「知识库无此方法论」，不编造。
> 2. **禁止基础内容**：功能说明书式、基础教学式（含教安装/教基础操作）、猎奇新闻式、无带走物式四类反模式一票否决，命中即整份重写。
> 3. **禁止瞎编乱造**：选题必须来自真实市场清单（技能市场/专家市场真实存在的 skill/专家）；写"实测"必须真实跑通并附成果证据（录屏/截图/文档）；未真实跑通一律不得称实测。
> 4. **违规即返工**：产出被用户判定"没按知识库/瞎编/基础教学"时，整份重写，不修补。
> 5. **交付前必过自检清单（强制闸门）**：定稿后按文末「P6 交付自检清单」逐项核对，清单式输出「标准卡 / 要求 / 本稿落位 / 判定 ✅⚠️❌」；任一 ⚠️/❌ 先整改再重跑全表，全部 ✅ 才允许交付。

## 对标模板（2026-11-01 拆解固化：鉴锋Agent「WorkBuddy小技巧」系列）

> 拆解对象：抖音「WorkBuddy小技巧 第四期｜怎么用WorkBuddy做百万播放同款动画」，56s/合集5集，发布17h：赞1972/评论4890/藏279/转410（评论=点赞2.5倍，评论区是主战场）。全程真实录屏、无口播（字幕+录屏+BGM）。本模板已被用户确认作为 P6 参考，但**不得复制"累计播放520万"结果佐证钩子**（账号无此资产，抄了=瞎编）。

### P6 固定结构：3 步清单骨架（每步大字幕标题+副标题，2-3 秒一个信息点）

| 步 | 段名 | 画面 | 口播方向 |
|---|---|---|---|
| 01 | 找到技能 | 展示 WorkBuddy 技能市场/专家页，搜索技能名并添加（真实录屏） | "搜 XXX，点添加，30 秒装好" |
| 02 | 输入什么 | 展示真实输入框：放操作指令/素材，说清要什么（真实录屏） | "把 XX 丢进去，说清要 XX" |
| 03 | 拿到成果 | 展示生成/导出，拿到一个具体成品（成果证据） | "一页纪要/清单/成品，直接能用" |

### 钩子（P6 用过程见证，不用结果佐证）

- **可用**：数字式（1分钟/0元/3步）、利益式（"用一次就回本"）、痛点式（"还在手动整理会议记录？"）、反差式（"别人 3 小时，它 1 分钟"）
- **禁止**："累计 X 万播放"类账号资产佐证（无此资产=瞎编）；"XX 大师推荐"类无来源背书
- 钩子 ≤20 字、前 3 秒、有具体名词/数字、指向核心论点（"1 分钟跑出 XX 成果"）

### CTA（评论区简单钩子，符合全局 CTA 规则）

- "留言领取 XX 清单/提示词模板" / "评论区扣 1" / "关注，明天继续更一个技巧"
- 领取物必须真能用（可复现的操作提示词/检查清单），**不是** PPT 代做/prompt 包式红海货（p1_ARF9PH1jatc 禁令）

### 其他可复制点

- 全程真实录屏 WorkBuddy 界面（技能市场/输入框/生成导出），可信度靠画面
- 系列化心智：「WorkBuddy 每日技巧 第 N 期」合集，日更追更
- 降预期防劝退：「先完成一个小作品」「新手别急着做大片」
- 结尾给成品画面（生成物实体可见）

## 每日执行流程

```
取当日选题（日历 P6 列 → 选题库 P6 区编号）
  → 查知识库（选题/案例库模块）
  → 真实跑通（在 WorkBuddy 用该 skill/专家执行一次，产出录屏/截图/文档成果；跑不通→换题回填）
  → 出分镜（3 步清单骨架 + 过程见证钩子 + 评论区领取 CTA + 分镜表，格式沿用 lewis-video-director 决策7 12 列或 doubao-shortvideo-writing 7 列）

  → 交付（飞书分镜文档 present_files + 回填日历备注/选题库 G 列分镜链接）
```

## 与 P4 边界

- P4 = WorkBuddy 系统实操（工作台搭建/旗舰版值不值/生态联动），P6 = 单技能单成果快技巧；同日并存时 P6 走"快技巧"粒度（1 个技能 1 个成果，60s 内）
- P6 界面展示沿用 P4 约束：涉及 WorkBuddy 界面展示 = 仅展示、指明展示**哪个区**（左导航/中对话区/右结果区）、避免 2 秒跳出；P4 系列延续只在一个内容类内推进，P6 同理不跨类

## 脚本准确性保障（沿用 lewis-video-director 四层防线）

1. **事实核源**：技能名/专家名/免费属性必须来自真实市场清单或官方页面，口播数字有来源
2. **声画契约**：逐镜「画面真实发生的事 = 口播讲的事」；讲该技能只用该技能真实界面，禁止近似界面冒充
3. **规则闸门**：写前查库 → 按命中标准写 → 写后自检
4. **交付验证**：定稿后回读一遍改后全文，旧错误表述确认清除

**核心论点锚定**：开写前先定「核心一句话」（如"1 分钟跑出 XX 成果"），钩子/3步/结论/CTA 四段全部指向它；结论卡必须回答钩子的问题。
