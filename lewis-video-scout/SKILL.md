## CTA硬规范（视频里只说私信，不提星球）

### CTA公式（每条选题必须遵守）

```
私信【关键词】领我做的XX（可直接用的东西）
```

**关键词**：2-4个字，好记好打，如【工具】【效率】【自动回复】
**领的东西**：必须是刘易斯做的、可直接导入/复制/使用的东西，不许是"清单""模板""检查表"这种AI能生成的泛泛之物。

### 合格CTA vs 不合格CTA

| 不合格（AI能生成） | 合格（刘易斯独有） |
|---|---|
| 私信领避坑清单 | 私信【工具】领我常用的3个工具配置文件 |
| 私信领效率模板 | 私信【效率】领我自己用的效率诊断表（可直接填） |
| 私信领教程 | 私信【自动回复】领我做的skill（导入即用） |
| 私信领方法 | 私信【生产线】领我的架构图+配置说明 |

### 三层引流路径（视频→私信→星球）

```
视频层：只说"私信我【关键词】领XX"，绝对不提知识星球
    ↓ 观众私信
私信层：自动回复 = 资料 + 星球软推广
    ↓ 观众领资料后建立信任
星球层：「豆包工作一人公司」，前100名免费
```

**私信自动回复统一模板：**
```
这是你要的【XX】，直接就能用：
[文件/链接/使用说明]

这些内容来自我的知识星球「豆包工作一人公司」，
里面有我做的所有skill、工作流、踩坑记录，每周更新。
目前前100名免费加入，扫码即可：
[星球二维码/链接]
```

**红线：视频正文、口播、字幕里绝对不许出现"知识星球"四个字。**

## 选题三来源（按优先级）

1. **30天选题库挑**：creator-content-calendar 维护的选题库里按排期挑（最稳）
2. **自家内容改写**：把公众号文章/课程/skill里的一个金句、一张对比图、一个反常识结论单独拆成一条视频
3. **多平台热点过滤**：抖音/视频号/即刻 AI 圈热点，只留"能落到一个具体工具动作"的——纯新闻八卦淘汰

## 每条选题必带字段

```
【支柱：P1/P2/P3/P4】【系列：XX系列NN】
《钩子标题（>6字，内置读者会搜的词）》
前3秒口播：一句钩子（反常识/冲突/数字，不要"今天我们聊聊"）
反转：推翻什么常见认知
观众带走什么：具体成果（配置文件/Prompt/skill/方法，不是"知识"）
建议时长：15-45s / 45-90s / 90-180s
分镜方向：逻辑图推镜 / 产品录屏演示 / 对比分屏 / 金句大字海报
CTA：私信【关键词】领我做的XX（按CTA公式写）
钩子强度：S/A/B（S/A才进推荐）
```

---

## 钩子强度三连验证（S/A/B判定）

1. **停得住吗**：刷到的人1.5秒内会不会停（标题+前3秒钩子）？
2. **看得懂吗**：不需要背景知识也知道在讲什么？
3. **想私信吗**：60秒后观众想私信领那个具体东西？

三项全过=S；缺一项=A；结构性缺失=B，不推荐。

## 爆款选题结构库（出题时直接套骨架）

### 五条标题/选题骨架（按内容类型选）

| 骨架 | 公式 | 适用支柱 | 示例 |
|---|---|---|---|
| **A. 痛点提问+数字清单** | 「XX话多又费X？先改这N项设置」 | P2教程 | 「豆包工作话多又费Token？先开这3个设置」 |
| **B. 反常识揭秘** | 「你以为X，其实是Y」/「90%的人都用错了X」 | P1避坑 | 「别再收藏AI工具了，你缺的不是工具是判断力」 |
| **C. 对比分屏** | 「没有X vs 有X，差了一个时代」 | P4展示 | 「有总导演和没总导演的视频，节奏差多少」 |
| **D. 清单盘点** | 「N个你不知道但天天在用的AI能力」 | P1/P2 | 「我常用的3个AI工具，每个都省我2小时」 |
| **E. 金句大字** | 一句反常识判断直接做标题 | P1/P3 | 「AI不是来抢工作的，是来统一接口的」 |

### 骨架使用规则
1. P2教程优先用A（数字清单=收藏驱动）
2. P1避坑优先用B/E（反常识=转发驱动）
3. P3实战优先用E（第一人称金句=完播驱动）
4. P4展示优先用C（对比=关注驱动）
5. 标题三件套堆叠：反常识感+具体数字+痛点词

## 爆款标题六元素检查（写每个标题必过）

> 来源：袁六伟《爆款标题方法论》。每个标题必须命中≥3个元素，否则重写。

| 元素 | 作用 | AI赛道贴法示例 |
|---|---|---|
| **贴标签** | 让人对号入座 | 一人公司老板 / 装了一堆AI工具却不会用的人 |
| **造冲突** | 两个不该同时发生的结果 | "AI工具买了一堆，老板却越来越忙" |
| **留悬念** | 问题说清，方法留一半 | "你用AI越用越累，可能漏了这一步" |
| **反着来** | 推翻常识 | "别再学提示词了" |
| **搞擦边** | 一点"你居然敢这么说"的越界感 | "报AI课之前，先把你现在这个工具用透" |
| **给好处** | 看完带走具体收益 | 每天多出2小时 / 省一半Token |
