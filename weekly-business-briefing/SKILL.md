# 每周经营播报（S3）

## 技能定位

每周一把"盘子"端出来：有哪些商机、各自健康度、哪些要救、哪些要推。让销售和管理者**在同一份事实**上对齐，而不是靠记忆开会。

## 触发场景

| 触发方式 | 触发条件 |
|---|---|
| 定时触发 | 每周一 09:00 自动执行 |
| 主动调用 | 销售问"本周商机进展如何？""上周经营怎么样？" |

## 输入

| 输入字段 | 来源数据表 | 说明 |
|---|---|---|
| 本周商机列表 | T3 销售漏斗 | 全部在管商机及健康分 |
| 经营指标 | T6 经营看板 | 漏斗总额、阶段分布、回款情况 |

## 执行步骤

1. **取数汇总**：读取 T3 全部在管商机，按阶段分组统计金额。
2. **健康分级**：调用商机体检口径，将商机标为红/黄/绿。
3. **找变化**：对比上周，标记阶段后移、金额下调、新增/丢失商机。
4. **生成播报**：输出总览 + 红黄绿清单 + 下周重点，末尾附一句管理者视角。

## 输出模板

```
【每周经营播报】2026-10-05（W41）
一、总览：在管 8 单，总额 320 万；本周新增 1 单（15 万），赢单 1 单（22 万）
二、健康度分布：绿 3 / 黄 3 / 红 2
三、重点关注：
  🔴 XX 客户（80 万）：同阶段停滞 21 天，报价后未回应 → 本周约决策人
  🔴 YY 客户（30 万）：健康分从 62 降至 48，关键联系人离职风险
  🟡 ZZ 客户（50 万）：预计成交日临近（11-15），尚在方案阶段
四、下周重点：3 场关键拜访 / 2 个报价待评审 / 1 个丢单需复盘
五、管理者视角：本月漏斗总额环比 -8%，主要缺口在方案报价阶段
```

## 边界与红线

- 只汇总不决策：播报是事实呈现，动作由人排定。
- 红黄绿按健康分口径自动判定，不人为调色。
- 敏感信息（丢单原因、人员风险）如实呈现，不美化。
