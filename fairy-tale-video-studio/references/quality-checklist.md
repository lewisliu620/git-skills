# 质检清单（每集交付前逐项验收）

> 每集成片交付前，按下表逐项核对；任一未过不交付。可加 `ffmpeg -i 成片.mp4` 抽验时长与流。

## 目录

- 内容安全（一票否决）
- 文本与配音
- 时间轴对齐
- 画面
- 成片规格

---

## 内容安全（一票否决）

- [ ] 教育点单条聚焦，无恐怖/暴力/迷信/烟酒/涉性/危险模仿/歧视元素
- [ ] 结局温暖正向 + 点题寓意；钩子只做正向期待，不做恐惧悬念
- [ ] 符合《未成年人保护法》(2024修正)、《未成年人网络保护条例》、《未成年人节目管理规定》

## 文本与配音

- [ ] 旁白 500-700 字、每镜一句、总时长 2-3 分钟
- [ ] 角色音色与音色锁定表一致（同角色逐字复用音色描述），无漂移
- [ ] 各段响度平稳（loudnorm -16 LUFS 后），无忽大忽小
- [ ] 段间衔接自然，无缺段/明显停顿

## 时间轴对齐

- [ ] 切点来自真实时间戳（analyze_audio 转写），不是语速估算
- [ ] 窗口/字幕时间 = 配音时间戳 + 3s（片头 adelay）
- [ ] 逐句抽检：**谁在说话，画面里就有谁；台词实物（帽子/围巾/球等）在画面可见**
- [ ] 字幕出现/消失与台词起止一致（±0.3s 内）

## 画面

- [ ] 9:16 竖版 1080×1920，全系列统一
- [ ] 水彩绘本风与画风锚点一致，角色形象与角色卡一致（无漂移）
- [ ] 同一张图多窗复用时段开了不同运镜，无连续相同画面
- [ ] 片头标题、片尾预告卡模板复用

## 成片规格

- [ ] 时长 = 3s 片头 + 配音时长 + 3s 预告（±0.3s）
- [ ] h264 + AAC 192k，1080×1920，25fps，yuv420p
- [ ] 文件命名 `<集名>_第N集成片[_v版本].mp4`，改版不覆盖旧版
- [ ] 已通过 `present_files` 交付，可本地直接播放
