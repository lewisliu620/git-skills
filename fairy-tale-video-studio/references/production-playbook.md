## 情节-画面元素对应清单

逐句核对台词与画面，出现以下情况必须补图（基于核心锚点 CDN URL 用 `image_edit`，不用纯文生图重画）：

- **台词实物未入画**：例"我的帽子分你一半线"→ 画面必须出现帽子 → 补"跳跳戴大红毛线帽"图。
- **关键动作无专属镜头**：例"跳跳，围巾借你"→ 需要"递围巾"动作 → 补"米米递围巾、跳跳探身接"图，用两窗一递一接。
- **说话人无对应画面**：谁开口，画面主体应是说话人或对话双方；旁白才允许用场景/特写空镜。

判定口诀：**"台词里有 X，画面里就得有 X；谁在说话，画面里就得有谁。"**

## 踩坑记录（14 条，照抄避坑）

1. **PowerShell 变量插值**：`$seg$i_norm` 会把 `$i_norm` 当变量名 → 必须写 `seg${i}_norm.wav`。
2. **concat list 必须绝对路径**：相对路径会被拼上 list 文件所在目录前缀（`ep1_video\v3\ep1_video/v3/s01.mp4`）导致找不到文件；Windows 用正斜杠绝对路径：`file 'C:/.../s01.mp4'`。
3. **`-vf` 是输出选项**：必须放在输出文件前；放在 `-i 音频.mp3` 前面会报 "cannot be applied to input url ...mp3"。
4. **ffprobe 不存在**：用 `ffmpeg -i` 探测时长/流（stderr 输出 Duration/Stream）。
5. **逐字稿不走 docs +fetch**：纪要文档只含"智能章节"粗粒度时间戳（00:00 / 01:05）；逐句转写须 `lark-cli note +transcript --note-id <vc-node-id>`（vc-transcribe-tab 的 vc-node-id 即 note_id）。
6. **图片 CDN 短链可能过期**：再次引用做 image_edit 前，先用 FileBatchUpload 上传本地图取新 URL（`https://aka.doubaocdn.com/s/...`）。
7. **分片文件名前导零**：`s$i.mp4` 循环会漏零（s1 而非 s01）→ 用 `"{0:D2}" -f $i`。
8. **text_to_audio_plus 下载的 `.bin` 实为 WAV**（pcm_s16le 40000Hz 立体声）：改名 `.wav` 后 loudnorm 归一化、转 44.1kHz 再拼接。

### 一键合成脚本踩坑（build_episode.ps1 实测，2026-10-05 smoke test）

9. **UTF-8 无 BOM 中文脚本在 PowerShell 5.1 解析错乱**（报 Missing closing '}'、中文变乱码）→ 脚本文件必须保存为 **UTF-8 with BOM**（文件头 EF BB BF）。
10. **CSV 表头被当数据行**（报 Cannot convert value "start" to type "System.Double"）→ CSV 去掉表头，或在脚本里加 `if ($p[0] -eq "window") { continue }` 兼容。
11. **PowerShell 把含单引号的滤镜串传坏**（报 Unknown function in '=iw/2-(iw/zoom/2)'，引号/变量被吞）→ 滤镜图写临时 txt 文件，用 `-filter_script`（逐窗）读取，不直接走命令行参数。
12. **PowerShell 5.1 插值吞变量（最隐蔽）**：`"d=$d:x='$x'"` 实测输出 `d=='iw/2-(iw/zoom/2)'`——`$d:x` 被误解析，225 和 `:x=` 全部丢失 → 任何变量与 `:` 相邻必须写 `${d}:x='${x}'`。
13. **ass 滤镜路径盘符冒号被当选项分隔符**（报 Unable to parse option value "...as image size"）→ 盘符冒号转义 `C\:/Users/...`，路径统一正斜杠；drawtext 字体路径同理（`C\:/Windows/Fonts/msyh.ttc`）。
14. **简单滤镜与复杂滤镜不能同流混用**（Simple and complex filtering cannot be used together for the same stream）→ 烧字幕 + 音频 adelay 必须合成一张复杂滤镜图，用 `-filter_complex_script fc.txt`（`[0:v]ass='...'[v];[1:a]adelay=3000|3000,apad[a]` + `-map "[v]" -map "[a]"`），不能一个走 -vf/-filter_script 另一个走 -filter_complex。
