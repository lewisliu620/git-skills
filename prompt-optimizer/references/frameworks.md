# 6大主流提示词框架详解

## 目录

- 框架选择速查表
- 1. RTF（最轻量）
- 2. ICIO（工程化）

- 5. CRISPE（重角色和示例）

## 框架选择速查表

| 任务类型 | 用哪个框架 | 复杂度 |
|----------|-----------|--------|
| 简单明确的小任务 | RTF | ⭐ |
| 技术/工程/数据处理 | ICIO | ⭐⭐ |

## 1. RTF（最轻量）

**适合**：简单明确的小任务，一句话就能说清的。

```
R 角色（Role）：你是谁
T 任务（Task）：做什么
F 格式（Format）：输出成什么样
```

**例子**：
- "你是文案，帮我写个产品标题，输出30字以内的短标题。"

---

## 2. ICIO（工程化）

**适合**：技术开发、数据处理、有明确输入输出的工程任务。

```
I 指令（Instruction）：具体要做什么
C 背景（Context）：上下文是什么
I 输入（Input）：给你什么素材
O 输出（Output）：要什么格式/结果
```

**例子**：
- "把这个CSV数据清洗一下，背景是用户行为日志，输入是data.csv，输出是清洗后的表格+统计报告。"

---

## 3. CO-STAR（业界最流行，默认用这个）

**适合**：内容创作、营销、通用知识工作。

```
C 背景（Context）：为什么要做这个
O 目标（Objective）：最终要什么
S 风格（Style）：写作/视觉风格
T 语气（Tone）：正式/口语/犀利/亲切
A 受众（Audience）：给谁看
R 输出格式（Response）：文档/表格/PPT，篇幅
```

**例子**：
- "背景：知识星球开营，目标：写一篇开营公告。风格：亲切。语气：像朋友。受众：付费星友。输出：飞书文档，800字。"

---

## 4. ROSES（重实操）

**适合**：实操教程、SOP、操作指南类内容。

```
R 角色（Role）：你是谁
O 目标（Objective）：最终要什么
S 场景（Scenario）：具体在什么情况下用
E 期望解决方案（Expected Solution）：最后产出什么
S 步骤（Steps）：一步一步怎么做
```

**例子**：
- "你是AI老师，目标：教大家怎么用豆包写周报。场景：职场人每周要写周报。产出：一步一步的操作教程。步骤：1.打开豆包 2.输入提示词 3.生成 4.修改。"

---

## 5. CRISPE（重角色和示例）

**适合**：创意写作、角色扮演、需要few-shot示例的任务。

```
C 能力（Capacity）：你具备什么专业能力
R 角色（Role）：你现在扮演谁
I 背景（Insight）：来龙去脉
S 陈述（Statement）：具体需求
P 个性（Personality）：你的说话风格
E 示例（Experiment）：给几个参考例子
```

**例子**：
- "你是资深文案，扮演小红书博主。背景：推荐一个AI工具。需求：写一篇小红书笔记。个性：活泼接地气。示例：参考这篇爆款笔记的风格..."

---

## 6. BROKE（深度项目级）

**适合**：大课、重要方案、项目级产出。

```
B 背景（Background）
R 角色（Role）
O 目标（Objective）
K 关键结果（Key Results）：验收标准
E 迭代方向（Evolve）
```

**例子**：
- "背景：做一门AI实战大课。角色：课程设计师。目标：4期连载。关键结果：8项硬标准全过、有模板包、有端到端样例、有作业。迭代：每周根据反馈调整。"

---

## 怎么选？

1. 先判断任务类型
2. 对号入座选框架
3. 拿不准就选CO-STAR（最通用）
