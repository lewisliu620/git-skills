# 客户画像生成（S7）

## 技能定位

见客户前 3 分钟备好全部档案。把散落在各处的客户信息（基础资料、联系人、往来记录、商机、回款）聚合成一张**可用的画像卡**，让销售带着事实去拜访，不临时翻聊天记录。

## 触发场景

| 触发方式 | 触发条件 |
|---|---|
| 新记录触发 | 客户建档或资料更新时自动执行 |
| 主动调用 | 销售说"给 XX 建个客户档案" |

## 输入

| 输入字段 | 来源数据表 | 说明 |
|---|---|---|
| 客户名称 | T1 客户台账 | 唯一标识 |
| 行业 | T1 客户台账 | 制造业/高科技等 |
| 规模 | T1 客户台账 | 人数、营收量级 |
| 联系人 | T1 客户台账 | 角色、联系方式、已建立关系 |
| 往来记录 | T5 关系与跟进 | 历史互动、拜访、约定 |

## 执行步骤

1. **基础聚合**：读取 T1 客户主数据。
2. **关系聚合**：读取 T5 联系人关系深度与最近互动。
3. **商机聚合**：读取 T3 该客户名下商机与回款状态。
4. **生成画像卡**：按下述模板输出，标注数据完整度。

## 输出模板

```
【客户画像卡】客户：XX 精密制造｜行业：制造业｜规模：300 人
一、基本信息：主营精密零部件，年采购软件预算约 50-80 万
二、联系人：
  - 王总（总经理/决策人）｜关系：信任｜上次互动：2026-09-20 拜访
  - 李工（IT 负责人/技术把关）｜关系：熟悉
三、商机：ERP 升级 80 万（方案报价阶段，健康分 62 黄）
四、回款：历史 2 单均按期回款（T4 记录）
五、风险提示：决策链中未见采购负责人，预算审批流程待确认
六、数据完整度：90%（缺采购环节联系人）
```

## 边界与红线

- 画像基于表内真实数据，不编造客户信息。
- 不自动新增或修改客户资料；更新动作由销售确认后执行。
- 涉及敏感信息（人员变动、投诉）如实标注，不猜测原因。
