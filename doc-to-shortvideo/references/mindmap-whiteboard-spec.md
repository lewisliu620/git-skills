# 思维导图白板风视频布局规范（Mindmap Whiteboard Spec）

> 来源：业界最佳实践调研（MindSea/CSDN/手绘思维导图法/Google Gemini 思维导图动画指南）+ 对标视频分析（洪涛同学LovTech《什么是Harness》1127赞）。
> 适用：HyperFrames / Remotion 代码渲染的思维导图白板风短视频。
> 触发：当分镜风格为"思维导图/白板笔记/知识结构图"时，本规范为硬约束。

---

## 一、画布与镜头

| 参数 | 规范值 | 说明 |
|---|---|---|
| 输出视口 | 1080×1920（竖版9:16） | |
| 布局方向 | **垂直树形图**：根节点在顶部，分支往下展开 | 不是左右辐射，是从上到下 |
| 场景机制 | clip 场景切换（display:none/flex + opacity交叉淡入） | 不用镜头移动 |
| 逐次披露 | 每屏只出现当前讲解的那一个分支路径 | 根→分支A→分支B→全貌 |
| 场景切换 | GSAP opacity 0.4-0.5s crossfade | |
| 核心原则 | **从上到下逐次展开**：根节点先出现→然后一级分支→然后该分支的子节点依次往下 | |

## 二、字号层级（硬规范，不许乱设）

| 层级 | 字号 | 字重 | 用在哪 |
|---|---|---|---|
| 中心节点 | **56px** | 700 bold | 核心主题词，蓝色圆角底块 |
| 一级分支标签 | **34px** | 700 bold | 分支名，带边框圆角块 |
| 二级分组标题 | **26px** | 600 semibold | 组名，左侧竖线标识 |
| 三级叶子条目 | **22px** | 400 regular | 具体内容，灰色 |
| 关键词高亮 | **22px** | 600 semibold | 同叶子字号，强调色 |

每层字号递减约20-30%，确保视觉层级一眼可辨。

## 三、间距规范（解决"字体挤在一块"的核心）

| 间距项 | 最小值 | 说明 |
|---|---|---|
| 组与组之间（margin-bottom） | **32-36px** | 二级分组之间必须有呼吸区 |
| 叶子行高（line-height） | **1.9** | 三级条目行距 |
| 分支标签到第一组 | **28px** | branch-label margin-bottom |
| 分支左右边距 | **60px** | 内容不贴边 |
| 留白占比 | **≥30%** | 画面不能塞满，要有呼吸区 |
| 中心节点到分支 | 视觉曲线连接即可，不要求固定距离 | |

## 四、颜色规范（≤4色）

| 角色 | 色值 | 用在哪 |
|---|---|---|
| 背景 | #0d0d0d（深黑） | 整个画布 |
| 中心节点底 | #2d5da3（深蓝） | 中心圆角块 |
| 分支A强调色 | #f0c040（金黄） | agent分支标签边框+关键词高亮+左竖线 |
| 分支B强调色 | #5b9bd5（浅蓝） | harness分支标签边框+关键词高亮+左竖线 |
| 正文文字 | #aaa（中灰） | 三级叶子条目 |
| 标题文字 | #e8e8e8（近白） | 二级分组标题 |
| 辅助文字 | #777（暗灰） | 副标题、footer |

**规则：**
- 同一层级用同一色；不同分支用不同强调色区分
- 强调色只用于关键词高亮（≤10%画面面积），不大面积铺
- 不超过4种主色

## 五、连接线规范

| 参数 | 规范 |
|---|---|
| 主分支线宽 | **3px** |
| 线型 | 虚线（stroke-dasharray: 10 7），手绘感 |
| 颜色 | 对应分支强调色 |
| 形状 | 贝塞尔曲线（Q命令），从中心节点弯向分支标签 |
| 动画 | strokeDashoffset动画画出，1秒 |

## 六、内容密度控制

- **每个节点1-3个关键词**，不用完整句子
- 层级≤4层（中心→主分支→子分组→叶子）
- 主分支≤7条（7±2法则）
- 一条视频只展示1个中心主题+2-4个主分支，不要贪多
- 叶子条目每组1-3条，多了拆成下一个镜头

## 七、树形图节奏模板（30秒，观点级逐次披露）

**核心原则：不是场景切换时整组出现，而是每个子节点（观点）按口播节奏逐个fade in——讲到"推理循环"时才出现推理循环，讲到"自我纠正"时才出现自我纠正。**

业界最佳实践（来源：Holma AutoLectures / QuickReel）：
- 先录配音，再按配音时间轴排每个元素的出现时机
- per-phrase reveal：2-4个词/一个观点为一组，不是逐字但也不是一整屏全出
- 元素在讲到它的时候才出现（element appears as it is mentioned）

| 时间 | 场景 | 出现的内容 |
|---|---|---|
| 0-3s | 标题叠加层 | "什么是XX？"+副标题 |
| 3.5-6s | 根节点 | 只显示根节点 |
| 6-13s | agent分支逐次展开 | 6.3s: agent标签 → 7.2s: 推理循环 → 7.8s: 推理循环叶子 → 8.6s: 自我纠正 → 9.3s: 自我纠正叶子 → 10.2s: 大模型 → 10.9s: 大模型叶子 |
| 13-21s | harness分支逐次展开 | 13.3s: harness标签 → 14.2s: 指令 → 14.8s: 指令叶子 → 15.6s: 工具与技能 → 16.2s: 叶子 → 17.0s: 环境 → 17.6s: 叶子 → 18.4s: 状态 → 19.0s: 叶子 |
| 21-24s | 完整树全貌 | 缩小版概览 |
| 24-30s | CTA | 结尾引导 |

## 八、踩坑清单

| 坑 | 后果 | 解法 |
|---|---|---|
| 分支宽度<500px | 文字换行挤在一起 | 内容最大宽度880px，居中排列 |
| 组间距<20px | "字体挤在一块" | margin-bottom≥32px |
| 字号层级不明显 | 看不出主次 | 严格按层级递减 |
| **一次性铺满整张思维导图** | **所有内容挤在一屏，观众眼花** | **逐次披露：每屏只露1-2组，用clip场景切换** |
| **用垂直滚动长画布做镜头移动** | **场景间元素互相穿透，全黑帧** | **改用clip场景交叉淡入淡出，不移动镜头** |
| **用display:none控制子节点逐次出现** | **hyperframes seek渲染时display切换不可靠，所有节点同时出现** | **改用opacity:0初始+GSAP to opacity:1，不用display控制** |
| 结尾CTA覆盖内容 | 检查报text_occluded | 这是故意的，加data-layout-allow-overflow |
| 字体没@font-face声明 | 渲染报错 | 必须加local()声明 |
| 留白不足30% | 画面拥挤压抑 | 每屏内容上下居中，四周≥30%留白 |

## 九、手绘白板风（rough.js方案）

**触发条件**：用户要求"手写版""白板风""字是写出来的""连线画出来"。

**技术栈**（全部CDN加载，0积分）：
- rough.js 4.6.6：生成手绘风格SVG线条（roughness=1.8, bowing=2）
- Google Fonts Ma Shan Zheng / Long Cang：手写中文字体
- GSAP stroke-dashoffset动画：线条逐段画出

**手绘线条实现**：
```js
const rc = rough.svg(svg);
const line = rc.line(x1, y1, x2, y2, { stroke: color, roughness: 1.8, bowing: 2 });
svg.appendChild(line);
// 动画：strokeDasharray=长度, strokeDashoffset=长度 → to strokeDashoffset=0
```

**动画顺序**：先画线（0.4s draw-on）→ 再淡入文字（0.5s blur消除）→ 再淡入叶子说明（0.4s）

**配色**：米白纸底 #fafaf5，主色 agent=#d4880f（橙黄马克笔），harness=#2563eb（蓝马克笔），正文 #2c2c2c，叶子 #777
