检索词构造：创作环节 + 内容类型（口播/知识/测评/带货）+ 目标（起量/涨粉/完播）+ 约束（时长/风格/平台）。脚本按 scenes/trigger/tags/title 关键词匹配打分 + 决策点模块加权 + 语义别名扩展（写脚本→钩子/开头/结构/完播）。

## 过滤（脚本已内置）

1. **production_mode**：默认只取 all_ai / hybrid，丢弃 manual
2. **一次 3-8 条**：按相关度取最相关，不整堆返回
3. **refresh_policy 时效**：stable 直接用；quarterly(90d)/monthly(30d)/weekly(7d) 须 status=verified 且 collected_at 在窗口内，否则脚本自动丢弃

## 应用与引用

把命中卡片的 steps 套进产出后，**必须标注 card_id + source + collected_at**（引用时保留卡内真实数据与来源链接，不转述来源 URL 之外的编造内容）。

**分镜文档内方法论引用章节（标准模板，2026-10-30 固化）**：每次分镜生成/修正，在文档「创意策略」下插入「★ 知识库方法论应用与引用（写脚本环节查库 · 日期）」章节，逐条标注：card_id + refresh 状态 + collected_at + source URL + 具体应用位置（如「镜02 先抛困境钩子」「镜08 数字高亮」）。合规提醒统一补 A5-002 发布必选标签卡：全 AI 生成视频发布时主标签必选「含AI生成内容」，不得选「无需标注」。

## 无命中回退（脚本输出"(无命中)"时）

1. 放宽 tags，按同模块相邻卡兜底；
2. 换模块：该决策点无卡时查案例库找相似爆款结构；
3. 仍未命中 → 标注「知识库无此方法论」，按通用创作原则处理，**禁止编造方法论或冒充来源**。

## 何时不查库

- 纯格式化任务（转写/翻译/标题排版）不查；
- 用户已给明确指令和素材、不需要方法论参考时不查；
- 查库只用于需要创作决策的环节（选题、脚本、拍摄剪辑、发布前、复盘），避免每次调用都检索。
- **已有文档也要查库（2026-10-30 固化）**：更新/增强知识库整合前写的旧分镜，同样必须先查库再改，不因"文档已存在"跳过（典型：P4-02 旧分镜未含知识库引用，更新时补插方法论章节）。
