## 1. 成片标准一句话

**前 3 秒给观看理由，中间给可带走的动作，结尾给一个明确动作（评论区扣1/关注/转发）。** 任何一条不符合就是返工。

## 2. 钩子公式（前 2-5 秒）

| 钩子 | 用法 | 避免 |
| :--- | :--- | :--- |
| 成品/结果前置 | 先给完成品（工作台/图表/成片）再倒回过程 | 开头站桩介绍 |
| 反常识设问 | 挑战常见做法："看Star数选开源Agent？你被坑了" | "它好不好用呢？" |
| 痛点特写 | 具体烦躁瞬间：加班赶竞品分析、文件乱成粥 | 泛泛问"你有没有遇到过" |
| 强对比 | 前后/新旧/错误vs正确同屏 | 只说优点没画面 |
| 翻车瞬间 | 直接放 AI 荒诞画面+反应 | 铺垫半天才到笑点 |
| 时间账 | "这活以前3小时，现在4分钟" | 空喊"效率提升" |

时间规则：15s 前 2-3s 出钩子；30s 前 3-5s；60s+ 前 5s，并在 20-25s 处放次钩子或转折。

**前 2 秒不跳出（硬规则，防止观众划走）**：
- **0-2s 必须有静止焦点**：成品/结果**定格**（画面静止）+ 大字花字利益点——观众静音、快速滑动时也能 0.5s 看懂"这是啥、关我什么事"；纯滚动/纯口播在前 2 秒必跳。
- **前 2 秒口播只给短句**：≤12 字（如「全网爆火的个人工作台，你也有了吗？」）；长句拆到 3s 后，别让 30+ 字堆在开头。
- **定格帧要求**：无光标移动、无抖动、画面静止；录屏素材先定格 2s 再滚动。

## 3. 叙事结构（四类打法对应）

| 打法 | 结构 |
| :--- | :--- |
| 可模仿成品 | 成品前置 → 倒回过程（怎么搭）→ 揭示方法（几句指令）→ 行动引导 |
| 翻车喜剧 | 翻车瞬间前置 → 过程（指令→翻车→补救→再翻车）→ 正确做法收尾 → 系列化预告 |
| 时间账 | 痛点/结果前置（"2小时vs8分钟"）→ 完整工作流步骤 → 可照抄指令 → 收藏引导 |
| 决策/避坑 | 判断前置（"别急着装"）→ 3-5 个依据/检查项 → 明确结论（适合谁/不适合谁） |

## 4. 镜头节奏与分镜表

- 总时长 → 镜头数：15s=4-6 镜，30s=7-10 镜，60s=12-18 镜。
- 每 2-4 秒一次画面变化/信息推进：特写、屏幕录制、手部动作、对比、花字、道具切换。
- 避免连续 3 个以上同景别；录屏类用景别变化+口播穿插破单调。
- 标准 7 列分镜表：镜号 | 时长 | 景别 | 机位 | 画面内容 | 台词 | 音效/花字。
- 画面内容只写能被拍到的客观动作；台词短、口语化，无台词写（无台词）。
- 关键指令/步骤词压花字（观众要能截屏抄走）；花字≠字幕，别重复。

## 5. 封面与标题

- 封面 1-3 方案，文字不画进图（外部文案）；AI 工具类用成品截图/对比分屏/局部特写做底图。
- 标题公式：具体结果 + 反差/悬念（"3小时手搓人生管理台""合同审阅：我2小时它8分钟"）。
- 不用"震撼/炸裂/震惊"等营销腔。

## 6. 平台差异（单版本多平台分发）

| 平台 | 版本 | 调整 |
| :--- | :--- | :--- |
| 抖音 | 60s / 9:16（唯一成片） | 直接分发；CTA 用评论关键词（扣1）/关注 |
| 视频号 | 60s / 9:16（同一条） | 发布层微调：标题/封面文案/话题标签按平台改；CTA 改为「转发给需要的人」/关注 |

**成本原则：只做 1 条统一时长成片（60s / 9:16），双平台直接分发同一文件，不重剪、不做双版本。** 平台差异全部收敛到发布层（标题/封面/CTA/标签），制作层零额外成本。

- 选时长时以覆盖多平台的中间值为准：60s 是抖音中视频和视频号内容的通用区间，能完整讲清一个实操点。
- 节奏取双平台交集：每 2-4s 变化（抖音可接受）、完整有观点（视频号可转发），不单为某一平台极端化。
- 需要更长（如 90s+ 深度内容）时，仍只做一个时长版本直接双发，不另做切片版。

## 7. 全 AI 制作流水线

1. **选题** → 过 viral-video-topics 反模式质检，带「观众带走物」。
2. **分镜** → 7 列分镜表（含封面方案、视觉参考区、执行包、剪辑提示、平台适配）。
3. **AI 执行脚本** → 给 AI 的逐步操作手册：前置条件检查 + S1-Sn 操作步骤（每步：操作/录屏要点/给 AI 的指令/异常处理）+ 执行纪律（只录真实操作、指令逐字入画、失败不硬凑）。
4. **AI 操控真实应用录屏** → 按执行脚本逐步骤操作，全程录屏，每步留素材；按第 9 节「录屏区域约束」逐镜录指定区域。
5. **剪辑** → 按分镜表节奏：加速指令输入过程（1.5-2 倍）、保留 2 处"打字→发送→结果出现"因果感、镜11 型高潮点不剪短、总时长 ±2s。
6. **封面+字幕+花字** → 从成品帧截封面底图；字幕逐句；**花字压「指令原文」供截屏抄走**（不是只压步骤名）。
7. **发布** → 统一时长单版本（默认 60s / 9:16）抖音+视频号直接分发同一文件，仅发布层微调（标题/封面文案/CTA/话题标签），回填选题库分镜链接列。
8. **成片验收（硬性）** → 按分镜表逐镜对照：镜头一个不能少、总时长在验收区间（默认 50-60s）；不达标必须补录补剪，禁止交付缩水版。

## 8. 录屏硬约束（AI 执行体铁律，违反返工）

> 来源：P4-01 首版成片 43.7s（目标 60s）、静态截图轮播、无光标、镜头被压缩成 3 段——AI 执行体不受约束时必然缩水。以下六条写入 AI 执行脚本「执行纪律」，不得省略。

1. **真实操作**：全程只录真实操作，禁止静态截图轮播、贴图、PPT 式卡片冒充录屏；每帧必须是真实应用画面。
2. **光标可见**：所有操作镜头鼠标光标必须全程可见、轨迹清晰；**禁止隐藏光标、禁止无光标帧作为主画面**。
3. **镜头必须动**：禁止同一界面静止超过 4 秒；每 2-4 秒必须有画面变化（滚屏/放大/光标移动/点击/生成动画）。
4. **因果完整**：全片必须完整保留 **2 处「输入→发送→结果出现」** 因果过程（一次生成 + 翻车修复），可 1.5-2 倍速，不得剪断。
5. **翻车真实**：翻车镜头必须来自真实操作（如生活区日历格子被撑高），禁止摆拍/编造；压短 3-4s，不打断顺畅感。
6. **时长验收**：成片总时长必须在验收区间（默认 50-60s），分镜表镜头一个不能少；镜头缺失或时长不达标必须补录补剪，禁止交付缩水版。
7. **实测真实性（2026-10-31 固化，P1 browser-use 踩坑）**：分镜写"实测/装完能干啥/一次真实操作"之前，必须真实安装并真实跑通，录屏必须来自真实安装后的真实操作。未真实安装时，分镜必须降级为**官方素材版**并在标题/项目概览显式标注「官方素材版（未实测）」：素材只取官方仓库、官方 demo 录屏/GIF、官方文档安装命令；台词禁止"我实测/装完能干啥/一次真实操作"；带走物改为"官方 demo 演示 + 安装命令 + 官方文档链接"；剪辑提示注明"官方素材需打『官方 demo 演示』水印，不冒充本地实测"。禁止官方素材冒充实测，禁止编造安装/运行过程。

## 9. 录屏区域约束（每镜录哪、放大多少、光标在哪，分镜表固定）

> 分镜表必须含「录屏区域」列；道具清单注明「录屏工具开启光标录制」。

| 镜类型 | 录屏区域 | 放大要求 | 光标要求 |
|-|-|-|-|
| 成品展示/轮播/收尾 | 全屏 | 全屏 | 无要求（纯展示） |
| 身份+时间账过渡 | 全屏→输入框过渡 | 全屏→中景 | 光标可见 |
| 卡片/清单展示 | 全屏→局部 | 放大至 60% 以上 | 光标划过功能清单 |
| **输入框教学** | **输入框区域特写** | **放大至 70%** | 粘贴/逐段划过全程可见 |
| 发送动作 | 输入框+发送按钮同框 | 中景 | 光标点发送 |
| 翻车捕捉 | 出事模块局部 | 放大 50% | 光标指向问题处 |
| 翻车修复 | 出事模块+输入框同框 | 中景 | 光标打字补指令 |
| 功能验证 | 操作模块局部 | 放大 50% | 光标真点、真操作 |

## 10. 脚本与成片一致性（改版必查）

> 来源：P4-01 内容已改「打工人工作台」，标题/封面仍留「人生管理工作台」——标题说 A、内容演示 B，前后打架。

- **演示对象单一**：全片只演示一个对象（如「打工人工作台」），标题、封面文案、开头钩子、单段 Prompt、翻车落点、验证落点全部指向同一对象。
- **改版全链路同步**：改标题时同步检查 6 处——选题库标题、日历标题、封面文案、分镜表、单段 Prompt、CTA；一处不改就是前后不一致。
- **单段 Prompt 打法**：一段结构化 Prompt（目标→功能→风格三段）一次发出，消除逐句等待；镜头放大输入框、光标逐段划讲；观众截屏即抄走（对标参照视频：粘长 Prompt→逐段讲→一次生成）。
- **身份卡片**：3 种身份 Prompt 卡片（可截屏大字图）**用确定性图文方式生成（HTML/图文工具），禁止 AI 生图压文字**（必乱码）；卡片只放身份名+适用场景+Prompt 开头一句+功能清单，全文靠视频粘入环节展示。
- **钩子双用**：从众钩（「全网爆火」）+ 利害钩（身份痛点/时间账）并用，5 秒给足。
- **时间账必须真实数字**：作者真实整理耗时（如 30 分钟），不编；前置到身份钩后 3-8s（收藏钩）。
- **CTA 三连**：留言关键词（要 Prompt）→ 晒图（看谁最卷）→ 系列预告（下期做哪版）；**不在评论区发放长 Prompt 文本**（平台风险），用「留言『XX』，下期拆解」承接。

## 11. 成片质检清单

## 13. 分镜时长校验（2026-10-30 固化）

> 来源：P3 分镜合计约 47s，低于 50-60s 验收下限，交付时必须在文档中标注调整建议。

- 分镜成稿后**先做时长合计校验**：合计时长 < 50s 时在文档「剪辑提示/知识库引用」处标注「建议扩至 50s」的具体扩法（如镜10 扩至 8s、镜11 扩至 5s），镜头数与节奏不变；不静默交付缩水版。
- 校验口径：逐镜时长求和，与验收区间（默认 50-60s）比对；镜头数按 60s=12-18 镜核对。
