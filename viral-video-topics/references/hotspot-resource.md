## 1. 三问框架（每条热点必答）

过完判断标准后，必须把三问答案写进脚本大纲；三问任一答不出「具体动作」即弃或转储备。

| 三问 | 要回答什么 | 固定句式 | 要求 |
| :--- | :--- | :--- | :--- |
| ① 能用来干嘛 | 盘点用途与场景（办公/副业/学习/生活） | 「这个热点能帮你做3件事：①…②…③…」 | 用途必须落到具体场景（写周报/审合同/查资料/做图），不许抽象 |
| ② 能带来什么 | 价值写清：省时间/省钱/避坑/涨见识 | 「看完你能省XX/避开XX/先人一步XX」 | 价值必须可量化（省多少钱/几小时/少踩几个坑），并配真实花费对比；说不清价值=不追 |
| ③ 传递什么有用信息 | 信息增量 + 对观众的意义 | 「多数人不知道的是…」+「这意味着你的…会怎样」 | 增量必须是有来源的事实（数字/条款/机制变化），情绪观点不算 |

**填空示例（热点：OpenAI Pro 额度翻倍）**

- ① 能用来干嘛：这个热点能帮你做 3 件事——①重排订阅档位 ②大任务月底前跑完 ③合并限额前规划用量。
- ② 能带来什么：看完你能每月省 50 美元 + 避开 12 月合并限额的坑。
- ③ 传递什么有用信息：多数人不知道的是，Pro 额度翻倍只限新档位，12 月还要并入 ChatGPT × Codex 合并限额——这意味着你的订阅档位该现在就重排。

### 三问答题卡（每条热点一张，答不出具体动作即弃）

- [ ] 用途 ×3：场景 × 动作 × 收益，填不满 3 个不过审
- [ ] 价值 ×1 句：可量化（省×钱 / ×小时 / 避开×个坑）+ 真实花费对比
- [ ] 信息增量 ×1 条：事实 → 来源 → 对观众的意义（情绪观点不算）

## 2. 资源化五步流程

流水线：**热点 → 3个用途 → 1个带走物 → 1个行动步骤 → CTA**。

1. **热点一句话**：是什么 + 1 个关键事实
2. **3 个用途**：逐条给场景（谁在什么场景用）
3. **挑 1 个做成带走物**：清单 / 对照表 / 步骤表（三选一交付）
4. **给 1 个明天能做的行动步骤**：观众今晚/明天照做（依据官方/公开素材，非必自测）
5. **CTA 领带走物**：评论区扣1 / 收藏 / 转发
6. 无热点 → 储备池兜底（一周不重复）

### 成本红线（与 P1/P4 的分工）

> 用户 2026-10-30 明确指令：「讲工具要实测才有价值，但成本高」。P2 是热点资源化线，不是实测线——**深度录屏/上手实测归 P1（开源 Agent 实测）与 P4（WorkBuddy 实操）**，P2 单条按 A/B/C 三级验证控制成本：

| 验证级 | 适用热点 | 素材来源 | 单条成本 |
| :--- | :--- | :--- | :--- |
| A 级 | 官方发布/更新类（新功能、新工具） | 官方公告/演示/文档 + 三问拆解 | 信息核实 ≤30 分钟 + 素材拼装 |
| B 级 | 价格/对比/规则类 | 官方定价页 + 公开评测/截图 | 同上 |
| C 级 | 翻车/争议/存疑点 | 才需要上手验证（可选做） | 按需投入 |

- 底线：讲人话、给依据（官方/公开来源）、不念参数；A/B 级取不到官方或公开依据 → 不追。
- 带走物必须是「可截图/可复制」素材（清单/对照表/模板），不是「看我的操作」。
- P2 的「能带来什么」用官方定价、公开数据说话，不靠自测画面证明。

### 流水线检查单（五步逐项打勾，缺一步不过审）

- [ ] 热点一句话（是什么 + 1 个事实）
- [ ] 3 个用途（场景 × 动作 × 收益）
- [ ] 1 个带走物（清单/对照表/步骤表 + 交付方式）
- [ ] 1 个行动步骤（明天照做）
- [ ] CTA（领带走物，双平台差异化）

## 3. 判断标准七条

每日定题先过 ①-⑥，全部不通过则从储备池抽一条实操题（一周内不重复）；储备题永远比播报题优先。

| # | 标准 | 判断口径 | 不通过怎么办 |
| :--- | :--- | :--- | :--- |
| ① | 相关度 | 职场人 + 小团队 AI 创业者会不会用到？我的观众每周用得到吗？和办公室工作/创业成本有关吗？**「普通人距离」红线：硬件（AI 眼镜/耳机/消费机器人/具身智能）、纯产业资本动向（融资/产能/并购）、纯科研突破——除非能落到普通人的「今天能买/今天能用」决策，否则一律不碰**（用户 2026-10-30 明确指令） | 纯科研突破/大厂人事/硬件/具身/与普通人无关的榜单一律弃 |
| ② | 可验证三级（实测按成本分级） | 不念参数、只讲人话是底线；验证分三级：**A 级**（官方发布/更新类）=官方素材+三问拆解即可，不要求自测；**B 级**（价格/对比/规则类）=官方定价+公开评测/截图可证；**C 级**（翻车/争议类）=才需要上手验证，可选做。**成本红线：P2 不做深度录屏实测，深度实测归 P1 开源实测 / P4 WorkBuddy 实操两条线；单条成本上限=信息核实 30 分钟 + 素材拼装，素材官方/公开优先**（用户 2026-10-30 明确指令：讲工具要实测才有价值，但成本高） | 纯观点/纯行业判断降级为储备题或放弃；A/B 级素材取不到官方或公开依据 → 不追 |
| ③ | 有带走物 | 清单/模板/方法/避坑至少一个，三选一交付：①视频内可截图素材 ②评论区自取（扣1/打关键词） ③私信关键词领取 | 选不出=不追；合规：只引站内，不给微信/二维码 |
| ④ | 纯发布不追 | 发布类热点拆成「对普通人的3个变化+下一步怎么用」，写得出才追 | 写不出即放弃。例：「新模型来了」=不追；「新模型来了，你的工作流哪3处会变+怎么接」=可追 |
| ⑤ | 时效窗口 | 突发热点 2 小时黄金窗；实操卡位 24-72h 出片（24h 实测片 / 72h 清单片）；可预见节点（发布会/新品/政策）提前 3-5 天预埋 | 超过窗口且无新动作价值 → 弃或转场景干货；弃单记入储备池备注，一周内不重复捡起 |
| ⑥ | P3 边界 | 本条是「这个热点现在帮你省时省钱/避坑」→P2；是「如何靠AI持续接单/做副业/建收入」→P3 | 热点里的商机讲不透 → 转 P3 选题池。口诀：「P2=今天就能用，P3=长期能赚钱」；拿不准先问「观众看完能不能马上照做」 |
| ⑦ | 兜底 | 当天无合适热点 → 从储备池按「一周不重复」顶上 | 储备题永远比播报题优先 |

## 5. 目标角色与钩子的关系（澄清固化）

> 用户 2026-10-30 质疑「P2 也有钩子，是不是不符合『教育→信任→转化』规则表」。澄清如下，后续选题作业直接引用：

- **四类目标角色（教育/发现/信任/转化，见 SKILL.md 选题库结构标准）是支柱分工，不是单条内容的流程顺序**：
  - P2 热点 = **发现 + 决策**（追热点抢流量 + 带走物沉淀决策价值）
  - P3 赚钱 = **教育/权威**（长期方法论）
  - P1/P4 实测/实操 = **信任**（真实操作证明可信）
  - **转化**在承接层（评论区/私域/后续服务）——「教育→信任→转化」是账号整体成长路径，不是每条 60 秒都要走完
- **钩子属于成片层（前 2 秒机制，viral-production.md「前2秒不跳出」红线），不属于目标层**：教育/信任/转化任何角色的内容都需要钩子防跳滑，没有钩子就没有被教育/信任/转化的机会。规则表从未要求「教育类不许用钩子」。
- P2 当日定题产出具体选题时，E 列目标角色标 **发现 / 决策**（如「发现+决策：抢热点流量，带走物=决策避坑」），不标信任/转化；机制行（判断/模板/储备）不标角色。
- 判定口诀：**角色管「这条内容在账号里站什么岗」，钩子管「这条内容前 2 秒让人看不看」——两件事，不冲突。**

## 6. 储备池 16 类两两打包清单

16 个题材类两两打包成 8 行（覆盖不减），每行 60 秒资源化 + 固定带走物：

| 行 | 打包题材类 | 资源化角度 | 固定带走物 |
| :--- | :--- | :--- | :--- |
| 1 | 新模型发布 / 大厂产品 | 「3个变化+怎么接」：别急着换，先答哪3处变化影响工作流+怎么接；不做跑分播报，只演示结果+真实花费对比 | 《换不换新模型决策清单》（换/不换两列条件）+ 1 个接入动作 |
| 2 | 开源刷屏 / 开发者事件 | 「凭什么火+装完能干啥」：讲清火点+普通人真实可用的3个场景+硬件门槛；开发者事件翻译成「你的工具在受影响名单里吗」 | 《本地跑开源模型硬件门槛对照表》+《受影响自查清单》 |
| 3 | 价格策略 / 工具上新 | 「怎么省+只留3个」：涨价/限额/免费调整后订阅怎么调最省；本周新工具只留3个，逐个讲淘汰理由 | 《订阅档位调整对照表》+《本周留用3工具清单》 |
| 4 | 争议话题 / 翻车案例 | 「我的判断+教训清单」：明确判断（该跟/别跟/看情况）+1个最小动作；翻车复盘→错在哪→避坑清单帮你省多少 | 《跟不跟判断树》+《避坑清单》（可直接对照自己的项目） |
| 5 | 资本动向 / 行业报告 | 「3个信号+趋势对你的影响」：**仅限软件/应用/内容层**——大厂软件工具动向、应用层报告数据→3个信号→你的工作流怎么变+1个可验证判断；硬件/具身/纯产业资本不在此列 | 《3信号自查表》（你的工作流中招几条）+《趋势要点卡》 |
| 6 | 取代焦虑 / 对比实测 | 「实话版清单+同任务横评」：哪些活真会被接走/哪些不会，各配1个应对动作；同一道工作题跑2-3个模型并排对比 | 《岗位被替代风险自查+应对动作清单》+《同任务对比表》（质量/速度/成本） |
| 7 | 海外热点 / 冷知识 | 「能抄的1个动作+反常识给方法」：硅谷在吵什么→挑1个明天能抄的动作；反常识只作钩子（例：AI给你的数字四成查无实据），落点必须是能马上用的方法 | 《可直接抄的1个动作》+《数字核验3步法》 |
| 8 | 政策条款 / 平台规则 | 「你的工作流哪里要改+行动窗口」：平台转登录墙/限流、条款悄悄更新→你的工作流哪里要改+窗口期内要做的3件事 | 《找资料备用路径清单》+《窗口期行动清单》（含截止时间标注） |

## 6. 业界依据

> 以下三类实证均取自 P2 设计调研简报，引用时保留来源标注；详细链接以调研简报为准。

### 6.1 中文实证

- 热点发布后 24h 内出「同一标准实测/盲测」，「不念参数，只演示结果+真实花费对比」（9208 赞片原句，来源：调研简报）。
- 热点功能→N 条清单；提示词做成可截图素材：「提示词我放视频里，大家直接截图保存」（5012 赞）。
- 评论区带走物真实话术：「具体提示词放评论区大家自取」「评论区打"提示词"」；合规红线：扣1只引站内，直给微信/二维码判导流。
- 开头 3 秒用「人群+N动作+收益」句式；24h 出实测片、72h 出清单片、超窗降级为场景干货。
- 选题至少命中 时效/争议/实用/情绪 之一，避免纯播报。

### 6.2 英文实证

- Matt Wolfe《50+ INSANE Ways To Use Nano Banana (For FREE)》42 万播放，频道均值 4.6 倍——热点→N 个用法清单体是验证过的破圈格式。
- Wes Roth 在模型 GA 次日即出片（《GEMINI 4 ARGON IS WEIRD...》发布于 Gemini 4 Argon 开放次日）。
- 描述区固定四件套：提示词/模板直链 + 逐条时间戳目录 + Newsletter + 工具站；置顶评论放资源链接（原话「The link is also pinned in the comments」）。
- 带走物三级火箭：轻量=描述区链接+置顶评论；中量=当场做出可打开的 Demo/清单；重量=周更 Newsletter/资源库。
- Matt Wolfe 选题窗口：工具发布/升级后 24-72 小时内出片，格式必须是「N 个你现在就能免费做的事」，不做抽象评论。

### 6.3 平台数据

- 收藏率衡量「可复用价值」：教程/模板/清单类内容天然高收藏（蝉妈妈口径）。
- 2026 年抖音流量考核向「收藏+复访」倾斜，收藏权重上升（第三方解读）。
- 热点话题生命周期约 48 小时，突发热点 2 小时内是黄金发布窗；可预见节点提前 3-5 天预埋。
- 60s/1-3 分钟片完播率合格线：良好 5-10%、优秀 >10%（蝉妈妈口径）；收藏率 ≥1% 为及格、干货类对标 3-5%（第三方实操口径）。
- 视频号=好友推荐+算法双轨，结尾引导语应从「点赞关注」改为「转给需要的人」；发布后 24h 数据差 ≠ 判死，留足 3-7 天观察窗。

## 7. 与现有方法论衔接
