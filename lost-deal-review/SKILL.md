# 输单复盘（S6）

## 技能定位

丢单不可怕，**同一个原因丢两次才可怕**。本技能把每次输单变成组织资产：先还原事实，再找根因，最后沉淀为可复用经验和流程改进点。

## 触发场景

| 触发方式 | 触发条件 |
|---|---|
| 新记录触发 | 商机在 T3 标记为"丢单"时自动执行 |
| 主动调用 | 销售说"XX 为什么丢了？" |

## 输入

| 输入字段 | 来源数据表 | 说明 |
|---|---|---|
| 商机记录 | T3 销售漏斗 | 阶段、金额、停留时长、健康分轨迹 |
| 失败原因 | 录入信息 | 销售自己认为的直接原因 |
| 复盘要点 | 录入信息 | 关键事件时间线、竞争情况 |

## 执行步骤

1. **事实回顾**：还原商机全生命周期——从线索到丢单的各阶段停留、关键节点动作。
2. **根因分类**：按下表定位根因（单选主因 + 可多选辅因）。
3. **经验沉淀**：提取 2-3 条可复用经验（下次怎么做）。
4. **流程改进**：提出 1 条流程改进点（什么环节该有动作但没有）。
5. **输出复盘卡**：写入商机备注并归档，供后续商机引用。

## 根因分类

| 根因类型 | 典型表现 |
|---|---|
| 客户根因 | 预算取消、内部流程中断、关键人更换 |
| 方案根因 | 需求误判、方案不匹配、交付能力不足 |
| 价格根因 | 竞品压价、报价策略失误、价值未说清 |
| 竞争根因 | 对手更强的关系/方案/品牌背书 |
| 执行根因 | 跟进断档、决策链未闭合、动作滞后 |

## 输出模板

```
【输单复盘卡】商机：XX｜金额：60 万｜周期：74 天
事实回顾：需求确认 21 天 → 方案报价 45 天 → 谈判 8 天 → 丢单
主因：价格根因（竞品压价 15%，我方未及时调整价值呈现）
辅因：执行根因（决策人 2 周未接触，报价后无跟进动作）
可复用经验：① 报价前先确认客户预算区间 ② 报价后 72 小时内必须有价值澄清动作
流程改进点：方案报价阶段增加"报价评审"环节（建议纳入 W 系列优化）
```

## 边界与红线

- 复盘对事不对人：不输出针对个人的批评性结论。
- 根因须有事实支撑：不得凭空归因。
- 复盘卡默认内部使用，不对外发送。
