# 微信表情开放平台规格与审核红线（已验证口径）

来源：微信官方设计规范与实投校验。全套素材必须一次配齐，任何一项不合格都可能驳回。

## 七类素材规格

| 素材 | 规格 | 硬性要求 |
|---|---|---|
| 主图（表情本体） | 240×240 | PNG/GIF，透明底 + 2px 白描边（白描边须被黑色描边包裹，即黑边包白边），单张 ≤500KB；一套 16 或 24 枚，含义词不得重复 |
| 缩略图 | 120×120 | 平台在批量上传主图后自动生成，无需手动准备 |
| 封面 | 240×240 | PNG，无文字 |
| 图标 | 50×50 | PNG，无文字 |
| 横幅 | 750×400 | JPG/PNG，**不透明、无文字、非白底**，≤80KB（艺术家主页横幅另有 ≤80KB 限制） |
| 赞赏引导图 | 750×560 | JPG/PNG/GIF（开启赞赏后出现，选填） |
| 赞赏致谢图 | 750×750 | JPG/PNG/GIF（选填） |

## 专辑字段口径

- 类型：静态表情 / 动态表情（GIF）二选一。
- 表情类型：真人拍摄 / 截图表情 / **卡通表情/其他**。
- 角色/内容：需选择主角，角色出现个数 ≥ 表情总数的 1/3（如宠物/动物角色 → 猫）。
- 表情风格：选 1–2 项（如日常 + 软萌可爱）。
- 表情主题：与主题相关的表情个数 ≥ 总数一半（如工作/职场）。
- 上架地区默认中国大陆；下载地区可选全球。
- 版权：填作者署名（如"刘易斯Lewis"）。
- 赞赏：勾选"接受赞赏"须先补全艺术家信息（名称、640×640 头像、主页横幅、50–80 字介绍）；赞赏引导语 ≥5 字。

## 审核红线（节选）

- 不涉黄赌毒、暴力血腥、政治敏感、宗教民族、侵权（明星/品牌/IP/肖像权）内容。
- 表情与含义词须一致；含义词不得重复、不得为生僻字。
- 透明底不是纯白底：主图四周透明，贴纸本体可带白描边。
- 横幅禁止纯白底与文字；封面/图标禁文字。
- 一套表情风格须统一（同一角色锚点），避免半套换风格。
