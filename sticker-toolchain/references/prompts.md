# 出图提示词模板与已验证教训

配合 `doubao-creative-design`（含 model-4.5 改写规则）使用。核心原则：**出图交给模型，规格交给代码**——模型只画角色与场景，文字、尺寸、描边、去底全部由脚本完成。

## S0 核心 IP 提示词模板（image_gen）

结构：总览（画幅方向+风格+色调）→ 角色分区描述 → 条件收束 → 不写比例数字（ratio 走工具参数）。

要点（角色锚点必须逐条写死，后续全部延展依赖它）：
- 体型/轮廓：如"圆脸橘色短毛猫、2 头身圆胖身形、白色肚皮"
- 五官：如"圆豆豆眼与淡粉腮红"
- 服装/道具：如"蓝色挂绳空白工牌"
- 风格/工艺：如"粗黑描边、扁平卡哇伊贴纸风、低饱和暖色"
- 构图：正面平视、居中、留白

## S1–S2 延展提示词结构（image_edit，参考图=核心 IP）

固定结构：**编辑目标 → 保留项 → 修改项 → 空间线性描述**。
- 保留项：角色身份、五官比例、描边风格、服装主色、构图锚点（必写，防漂移）。
- 修改项：姿势/表情/手持道具/视线方向（每次只变 1–3 项，保证系列统一）。
- 文案不在模型渲染：表情含义词由 process.py 用白字黑描边叠到底部（实测模型写中文糊字）。

## 批次纪律

- 一次最多 10 张；每张 `image_edit` 成功必须单独 `present_files` 交付后再出下一张。
- 串行出图，禁止并行（并行生成互相覆盖）。
- 锁定变量：每张都用 core-ip 作参考图（不是上一张），跨全套品牌层锚点一致。

## 四个已验证的坑

1. **prompt 写中文糊字** → 文字一律脚本叠字（微软雅黑粗体白字 + 5px 黑描边，y_center=212，字号 36/240px）。
2. **`background:transparent` 无效** → 生成图带浅色底（实测浅灰蓝 ≈(237,236,241)）；必须用 probe.py 采样背景色 + process.py 按距离做透明斜坡去底。
3. **必须串行出图** → 并行调用互相覆盖，只保留最后一张。
4. **PowerShell 5 内联 XML 必坏** → lark-cli 的 `--content "<XML>"` 会被拆参数；一律把 XML 写成本地文件再用 `--content "@./相对路径"`（相对路径必须带 `./` 前缀，否则可能按绝对路径解析失败）。
