# 商机体检（S1）

## 技能定位

给每一笔在管商机做"体检"，回答三个问题：这笔单健康吗？卡在哪？下一步做什么？
核心理念：商机不是靠感觉推进的，是靠**可见的健康信号**推进的。

## 触发场景

| 触发方式 | 触发条件 |
|---|---|
| 新记录触发 | 新商机录入 T3 销售漏斗时自动执行 |
| 定时触发 | 每周一 09:00 对全部在管商机批量执行 |

## 输入

| 输入字段 | 来源数据表 | 说明 |
|---|---|---|
| 商机名称 | T3 销售漏斗 | 唯一标识 |
| 阶段 | T3 销售漏斗 | 线索 / 需求确认 / 方案报价 / 谈判 / 赢单 |
| 金额 | T3 销售漏斗 | 预计合同金额 |
| 预计成交日 | T3 销售漏斗 | 客户承诺或合理推算的日期 |
| 最近跟进记录 | T5 关系与跟进 | 最近一次互动时间与内容 |
| 关系深度 | T5 关系与跟进 | 认识 / 熟悉 / 信任 / 依赖 |
| 客户分级 | T1 客户台账 | 战略性 / 重点 / 一般 |

## 执行步骤

1. **取数**：读取该商机在 T3、T1、T5 的关联数据。
2. **分项评分**：按下表对五个维度打分（各 0-20 分）。
3. **汇总**：五项相加得健康分（0-100），映射红黄绿。
4. **卡点判断**：对 <75 分且停留超过 14 天的商机，识别卡点类型。
5. **输出建议**：生成体检卡，给出下一步动作。

## 评分模型（各维度 0-20 分）

| 维度 | 打分规则 | 数据来源 |
|---|---|---|
| 阶段推进 | 近 30 天有阶段后移 +20；同阶段停留 7 天内 +15；14 天 +10；21 天 +5；超 30 天 +0 | T3 |
| 预计成交日 | 距离预计成交日 ≤30 天 +20；31-60 天 +15；61-90 天 +10；>90 天或已过期 +0（过期按风险提示） | T3 |
| 金额稳定性 | 金额无异常波动 +20；近 30 天下调一次 -5；多次下调按 -10 | T3 |
| 跟进频率 | 7 天内跟进 +20；14 天内 +15；30 天内 +8；超 30 天无跟进 +0 | T5 |
| 关系深度 | 依赖 +20；信任 +16；熟悉 +10；认识 +4；无记录 +0 | T5 |

**红黄绿阈值**：≥75 绿（健康推进）；50-74 黄（有卡点，需动作）；<50 红（高危，需介入）。

## 卡点类型识别

| 卡点类型 | 典型信号 | 建议动作 |
|---|---|---|
| 客户卡点 | 联系人迟迟不回复、内部流程停滞、关键人未接触 | 换接触策略：找更高层 / 找教练，重新约定下一步 |
| 方案卡点 | 需求匹配度存疑、方案未对齐、多次修改仍不满意 | 补一次需求澄清沟通，输出书面方案差异对照 |
| 价格卡点 | 报价后沉默、竞品压价、预算不足 | 提供价值证据（案例/ROI），或探讨分期/范围调整 |

## 输出模板

```
【商机体检卡】商机：XX｜健康分：68（黄）
阶段：方案报价｜金额：80 万｜预计成交日：2026-11-15
- 卡点：客户卡点（关键决策人 2 周未回应）
- 下一步：① 通过教练约决策人 30 分钟 ② 准备价值对照表
- 触发提醒：本周四前完成，超时升级黄色预警
```

## 边界与红线

- 只读分析：不自动修改商机阶段、金额。
- 评分仅供参考：是否推进由一线销售判断。
- 数据缺失时标注"数据不足"并提示补齐，不凭空推断。
