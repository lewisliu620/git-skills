# 三幕故事框架与年龄段适配

## 目录

- 示例骨架

## 三幕结构

| 幕 | 作用 | 内容要点 |
|---|---|---|
| 第一幕 开场引入 | 建立世界 | 主角登场、场景、愿望/问题出现 |
| 第二幕 冒险冲突 | 制造起伏 | 困难、伙伴、转折，情绪起伏但不过度惊险 |
| 第三幕 解决寓意 | 收尾升华 | 主角用正向品质解决问题，结局温暖，点出寓意 |

## 年龄段适配表

| 维度 | 3-6岁 | 6-10岁 |
|---|---|---|
| 时长 | 3-5 分钟 | 5-10 分钟 |
| 字数 | 约 600-1000 字 | 约 1200-2000 字 |
| 词汇 | 常见词、叠词、拟声词 | 可加简单成语，解释性融入 |
| 句式 | 短句、口语化、重复节奏 | 中短句，少量复合句 |
| 冲突强度 | 温和（找不到东西/迷路/想交朋友） | 适度（比赛失利/误会/挑战任务） |
| 寓意 | 单一明确（分享、勇敢、礼貌） | 可叠加（勇气+责任） |
| 角色数 | 旁白 + 2-3 角色 | 旁白 + 3-4 角色 |

## 各幕写作要点

- **第一幕（≤ 总长 1/4）**：用场景声音/天气/地点引入，让主角 30 秒内登场，一句话交代愿望或小问题。
- **第二幕（中段 1/2）**：一个主困难 + 一个小波折；伙伴出现帮忙但不抢主角风头；避免"突然得救"，让主角自己努力想办法。
- **第三幕（后 1/4）**：解决方式体现主角成长；结尾一句点题寓意，不用说教腔。

## 开放式结尾与续编（互动续编模式）

- **触发**：用户选择"互动续编结局"，或明确说"让孩子接着编""开放式结尾"。
- **结尾写法**：冲突基本解决、但留一个"接下来呢？"的悬念提问（如"就在这时，米米听到森林深处传来一阵新鼓声……接下来会发生什么呢？"），不点最终寓意，把话语权交给孩子。
- **续编规则**：
  - 认真接住孩子的回答，把孩子的想法转成剧情（哪怕天马行空），保持已有角色、世界观、音色不变。
  - 每轮续编 2-4 句台词 + 1 段旁白，节奏轻快；续编仍走三幕微结构（小目标 → 小波折 → 小收获）。
  - 每轮续编同样通过安全复检，保持正向。
  - 睡前场景下，孩子编完 2-3 轮后由旁白做一次小收尾（"月亮升起来了，故事先讲到这里"），不要无限续。
- **安全提示**：孩子说出敏感/危险设定时（如"把大灰狼杀掉"），温和改写为正向化解（"大灰狼吓跑了，再也不敢欺负人"），不展开。

## 示例骨架

```
[开场] 森林清晨 → 小兔米米想参加音乐会但没有乐器
[冲突] 找到旧木箱 → 学打鼓总失败 → 小鸟教节奏 → 音乐会前鼓坏了
[解决] 伙伴们一起修 → 用桶当鼓 → 演出成功 → 寓意：好东西在身边，伙伴最重要
```
