## 角色-音色对照建议

| 角色类型 | 音色描述 | 示例 |
|---|---|---|
| 旁白 | 温暖女声/男声，语速中等 | "30岁温柔女声，语气舒缓温暖" |
| 幼龄主角 | 清亮童声 | "6岁小女孩声音，清脆明亮，带点奶气" |
| 伙伴/配角 | 与主角区分 | "小男孩声音，活泼轻快" |
| 长辈/智者 | 低沉稳重 | "中年男声，声音低沉沉稳" |
| 淘气角色 | 傲娇/爱逞强，不阴森 | "小男孩声音，语气傲娇爱逞强" |

## 音色描述写法（文生音频 prompt 模板）

模板：`[年龄性别]声音，[音量/语气]＋[情绪]，自然地说台词：……`

示例：`8岁小男孩声音，活泼俏皮，在森林里兴奋地喊："哇，这里有好多果子！"`

注意：同一角色所有段落必须复用完全一致的音色描述前段，保证角色音色统一。

## 分段策略

- 单段音频 ≤ 120 秒；按剧本自然分段（场景/对话组切分）。
- 旁白段独立生成；角色对话按"角色聚集的对话组"分组合成。
- 段落顺序严格等于剧本顺序，拼接结果即完整故事。
- 默认纯人声；不加背景音乐（背景音乐属于 P2 阶段）。

## 响度归一化（消除音量忽大忽小）

- **问题**：各段 TTS 生成音量天然不一致（角色/情绪差异 + 模型随机性），直接拼接会忽大忽小。
- **做法**：每段拼接前用 EBU R128 响度归一化统一到 -16 LUFS（睡前故事常用标准）：
  `ffmpeg -i seg.wav -af loudnorm=I=-16:TP=-1.5:LRA=11 -ar 44100 -ac 2 seg_norm.wav`
- 归一化后再拼接；同角色各段归一化后音量也会一致。
- 若环境无 loudnorm，退而用峰值归一化 `-af volume=<目标增益>` 或 `alimiter`，效果以试听为准。

## 拼接与交付

- 用音频拼接工具（ffmpeg concat 或 mediakit）按顺序合并所有归一化后的段。
- 交付前通听一遍：角色音色是否统一、有没有明显停顿/缺段、响度是否平稳。
- 输出格式建议 wav/mp3，命名如《故事名_多角色配音.wav》。

## 音频模式（默认，多角色配音交付）

- **默认行为**：按分段策略逐段多音色合成 → 每段响度归一化 → 拼接为完整音频文件，与故事文本、剧本一并交付。
- **同角色统一**：同一角色所有段落复用完全一致的音色描述前段，保证角色声音统一。
- **切到对话框朗读**：用户说"朗读/直接读/不转音频"时，只交付故事文字与剧本，由客户端对话框朗读能力朗读，不调用音频合成。
- **切到纯文字**：用户说"只要文字"时，只输出故事文本与剧本。
