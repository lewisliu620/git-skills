## 场景 1：领导不喜欢我，也不喜欢我的工作方式（完整推演）

> 典型描述："领导不喜欢我，也不喜欢我的工作方式。""他总挑我毛病。""我的风格和他不对路。"
> 这是关系困境中最常见的一类，多数属于"可和解的矛盾"（风格、节奏、期望差），不是结构性对立——先按"和"的主策略推演。

### 第一步 察情：先分清事实与推测

**知彼（领导）**：
- 事实面：他最近在忙什么？他的考核指标是什么？他对谁的态度明显好/差？他夸过哪些人、哪些事？
- 推测面（标【待核实】）：他"不喜欢我"是公开表达过，还是我的感受？他的不喜欢，是讨厌我这个人，还是讨厌我的**交付方式**（节奏、沟通、风格）？
- 关键一问：**他到底要什么结果？** 大多数"不喜欢工作方式"的实质是"你的方式没在他要的结果上发力"，或"你的方式让他感到失控/不安"。

**知己（我）**：
- 我的工作方式是什么？例：重执行轻汇报、先做完再说、按自己节奏、不爱同步、加班多但沟通少。
- 对照"将有五危"：我有没有"忿速可侮"（被否定就上头）或"廉洁可辱"（被批评就玻璃心）？
- 我的硬实力是什么？哪件事离了我不行？

**知天知地**：
- 现在是项目期还是考核期？公司大方向是什么？我有无退路（内部转岗、外部机会）？

**五间盘点**：我能从哪 3 个渠道确认领导真实想法（周报/复盘记录、领导身边的同事、上一次绩效沟通）？

### 第二步 判势

- 矛盾性质：大概率是**可和解**（风格与期望差）——除非有明确证据（公开否定、利益冲突）才升级为结构性对立。
- 主策略：**和**（伐谋伐交）；备选：**待**（如果短期内无解，先立身）。
- 胜算自评：知胜有五 ≥3 项"是"即可启动。
- **不败底线（先行）**：把手上最重要的一件业务做到零瑕疵、可量化、可交付——先为不可胜。无论关系怎么变，先让自己"打不倒"。

### 第三步 定策（组合：形 + 谋攻 + 虚实 + 军争）

1. **形篇 · 先为不可胜**
   - 怎么用：不急着讨好，先让交付无可指摘。接下来的周期里，每个任务都"提前交付 + 主动同步 + 超出预期一点"。
   - 动作：选 1 个领导最在意的项目，本周内给出超预期的进展（不止做完，还附"下一步建议"）。

2. **谋攻 · 伐谋：让领导自己转变**
   - 怎么用：用"为了你的目标"话术重新包装自己的工作方式，而不是辩解"我的方式没错"。
   - 动作：下次一对一沟通时，主动问一句："您希望这个项目以什么节奏、什么形式推进？我按您要的来。"——把"方式之争"变成"目标对齐"。

3. **虚实 · 避实击虚**
   - 怎么用：不碰领导的权威与敏感点（如别在会议上当众纠正他），去找他真正头疼、又恰好没人做的领域深耕。
   - 动作：观察他最近最烦哪类问题（数据、交付、跨部门协调……），认领一件并做成。

4. **军争 · 避其锐气，击其惰归**
   - 怎么用：他刚批评完/情绪在头上时，不解释、不反驳，只说"收到，我调整"，24 小时后再书面同步调整方案。
   - 动作：本周若收到负面反馈，用"先接住、后调整、再汇报"三步应对，全程不辩解不甩锅。

### 第四步 行事（本周 3–5 个动作 + 禁忌）

动作：
1. 挑一件领导最在意的任务，提前 1 天交付并附一段"结果 + 下一步"的同步（先为不可胜）。
2. 约一次 15 分钟的一对一，开场就问他对这个任务的期望与偏好节奏（伐谋）。
3. 认领他头疼的一件小事并做好（避实击虚）。
4. 把每一次负面反馈都记录下来：他说了什么、我做了什么、结果如何（为复盘留证据）。
5. 观察他身边受重用的人是怎么汇报/怎么干活的，挑 1–2 个可借鉴的点（相敌）。

🚫 禁忌（火攻 + 九变）：
- 情绪上头时发长邮件、写小作文；
- 公开场合顶撞或纠正领导；
- 越级告状、找领导的对头站队；
- 赌气摆烂、消极怠工；
- 在同事面前抱怨领导。

期限：**4–6 周**。兵贵胜不贵久——到期按信号决定：好转→继续；无变化→换招（伐交）；恶化→启动"走"的预案。

### 第五步 复盘

- 观察信号：任务分配是否变化、批评措辞是否缓和、是否开始主动找你问意见、公开场合态度。
- 检查点：1 周（动作执行度）/ 1 个月（关系变化）。
- 换招条件：4 周无任何积极信号 + 有明确证据是结构性对立 → 转"伐交"（借关键人）或"走"（止损）。

## 场景 2：被排挤、被边缘化

- 症状：好项目轮不到你、重要会议不叫你、消息总慢半拍、存在感趋零。
- 错打法：抱怨、刷存在感、抢话、怀疑所有人。
- 兵法诊断：九地"静如处女，动如脱兔"——边缘期不是反抗期，是蓄势期；势篇"造势"——等一个能亮相的机会。
- 推荐组合：形（把本职做到无可替代）+ 势（借大项目/公开场合亮相）+ 用间（搞清楚为什么被边缘：是上一任的坑、是站队问题、还是能力没被看见）+ 九地（行动要快、一击即中）。
- 关键动作示例：①查明原因（3 个渠道）；②锁定 1 个高可见度任务主动请缨；③在周会/评审上做一次高质量呈现；④若半年无改善，启动"走"预案。

## 场景 3：与同事竞争同一机会

- 症状：同一晋升/项目名额，有强对手，且对方更会表现。
- 错打法：和对手正面撕、在领导面前贬低对方、焦虑内耗。
- 兵法诊断：虚实"致人而不致于人"——别跟着对手的节奏走（他卷你就更卷），回到你自己的主战场；谋攻"伐交"——让决定权人（领导）看到你，比打败对手更重要。
- 推荐组合：虚实（集中优势打自己最强的点）+ 谋攻（对齐领导的目标，而非对标对手）+ 形（把不可替代的成果做出来）+ 势（奇正：常规做扎实，竞聘时出奇招）。
- 关键动作示例：①弄清决定权人的评价标准（用间）；②做一件"只有你能做"的事；③竞聘材料突出"成果 + 下一步价值"，不攻击对手。

## 场景 4：被甩锅 / 背黑锅

- 症状：明明不是你的责任，锅却扣过来；解释无人听。
- 错打法：当场激烈自辩、找人对质、情绪化甩回去。
- 兵法诊断：行军"相敌"——先弄清事实链与责任链再动手；火攻"合于利而动"——不要为"爽"而战，为"澄清责任 + 止损"而战。
- 推荐组合：行军（收集证据、还原链条）+ 谋攻"伐兵"（就事论事摆证据，只谈事不伤人）+ 军争（选对方不在气头上、有旁证的场合澄清）+ 九变（杂于利害：想清楚澄清的代价与收益）。
- 关键动作示例：①整理时间线、邮件、聊天记录（证据）；②先私下与关键人（领导）一对一澄清，给台阶；③必要时书面留痕；④如果对方是惯犯→边界要立起来（火攻：合于利而动，不合于利而止）。

## 场景 5：要不要跳槽 / 该不该走

- 症状：长期不顺，犹豫是否离开，又怕走错。
- 错打法：情绪峰值时裸辞；或无限忍耐自我消耗。
- 兵法诊断：计篇"庙算"——走不走是决策，不是情绪；火攻"主不可以怒而兴师"——绝不在受气当天做决定；地形"认清地形"——先判断是"地"的问题还是"己"的问题（换公司能解决吗？）。
- 推荐组合：计篇（七计对比：新机会 vs 现处境的五事七计打分）+ 九变"杂于利害"（走：得什么失什么；留：得什么失什么）+ 用间（调研新机会的真实情况：团队、业务、直属领导）+ 作战"兵贵胜不贵久"（给现状一个明确的改善期限，到时见分晓）。
- 关键动作示例：①给现状设 8–12 周改善期限，期限内全力执行"和/待"策略；②同步做外部调研与机会盘点（不辞职也可以面试，掌握行情）；③把"走"做成有准备的行动，而非逃跑；④如走，骑驴找马、好聚好散（谋攻：全胜——不战而屈人之兵，离职也不留怨恨）。

## 场景 6：谈判：谈薪 / 争取资源

- 症状：想涨薪/要资源/争预算，但怕被拒绝、怕谈崩。
- 错打法：直接开价、情绪施压、威胁离职。
- 兵法诊断：虚实"致人而不致于人"——谈判前先掌握节奏与底牌；用间"先知"——摸清对方的盘子（预算空间、对标水平、你的替代成本）。
- 推荐组合：用间（调研市场价、内部口径、先例）+ 谋攻"知胜有五"（评估此局可谈性）+ 军争"以迂为直"（不直接要价，先谈贡献与价值，让价码自然浮现）+ 火攻"合于利而动"（明确自己的底线与退出条件）。
- 关键动作示例：①先把自己的成果量化成"给团队/公司省了多少钱、多了多少产出"；②选领导状态好、刚出成绩的时机开口；③给出 2–3 个可谈方案（薪资/资源/权限组合拳）；④谈崩也有台阶：留一句"那我先按现有条件把 X 做成，明年再看"，不撕破脸。

## 场景 7：情绪上头：想爆发 / 想裸辞

- 症状：被羞辱、被冤枉、被长期否定，想当场翻脸或立刻走人。
- 错打法：当场爆发、发怒邮件、裸辞、报复。
- 兵法诊断：火攻"主不可以怒而兴师，将不可以愠而致战"——这是全书对情绪决策最重的一句警告；九变"忿速可侮"——你越容易被激怒，对方越容易操控你。
- 推荐组合：火攻（一切动作以目标与利益为准）+ 九变（先停 24–48 小时再回应）+ 形（把情绪转化为把事做好的动力）+ 军争"以静待哗"（对方越乱我越稳）。
- 关键动作示例：①写下"此刻我想做什么 / 做了的后果 / 24 小时后我还想不想做"；②任何书面回复先存草稿，隔夜再发；③把"想爆发"的能量转去健身/写方案/准备跳槽材料；④真到不可忍，走人也要体面（全胜原则：不留把柄、不烧桥）。
