## A. 五事七计职场版

把兵法五事（道、天、地、将、法）与七计翻译成职场指标，用于"我 vs 此局"的实力与形势评估。给每项打分 1–5，总分低的维度就是"虚"处，不要在那里硬碰硬。

| 五事 | 兵法原义 | 职场含义 | 要问的问题 |
|---|---|---|---|
| 道 | 民心向背、上下同欲 | 方向认同、价值观契合 | 我的目标和领导/组织的目标对齐吗？多数人站哪边？ |
| 天 | 阴阳寒暑时制 | 时机、大势、周期 | 现在是进攻的好时机吗？行业/公司处于什么周期？ |
| 地 | 远近险易广狭死生 | 平台、位置、团队、赛道 | 我处在核心业务还是边缘？团队资源如何？ |
| 将 | 智信仁勇严 | 领导者（双方）的能力与性格 | 领导是哪种人？我自己的将德短板在哪？ |
| 法 | 曲制官道主用 | 制度、流程、规则、考核 | 规则对谁有利？考核指标是什么？谁在执行上有话语权？ |

七计对比（我 vs 对手/领导）：
1. 谁的方向更被认可（主孰有道）
2. 谁的能力与专业更强（将孰有能）
3. 谁占天时地利（天地孰得）
4. 谁的规则执行更严（法令孰行）
5. 谁掌握更多资源/支持（兵众孰强）
6. 谁准备得更充分（士卒孰练）
7. 谁的赏罚体系更认可他（赏罚孰明）

用法：得分对比后，**只在你占优的维度上发力，避实在虚**。全盘落后→判势为"走"或"待"。

## B. 知胜有五 · 此局判断

谋攻篇五条胜算，逐条对照当前处境（是 / 否 / 未知）：

1. **知可以战与不可以战** — 我清楚该不该正面解决、何时解决吗？（不知道就别打）
2. **识众寡之用** — 我知道怎么用自己手头的资源、筹码、人脉吗？
3. **上下同欲** — 有没有和我同心的人？（领导？同事？导师？盟友？）
4. **以虞待不虞** — 我准备充分、对方没防备吗？
5. **将能而君不御** — 我有没有足够的自主空间？还是被死死盯着？

判定：≥4 项"是"→ 可以主动出手；2–3 项"是"→ 走"和/待"，先补筹码；≤1 项"是"→ 此局不宜战，优先"先为不可胜"和"走"的预案。

## C. 战 / 和 / 走 / 待 决策表

| 条件组合 | 推荐主策略 | 理由（兵法依据） |
|---|---|---|
| 矛盾可和解 + 我有胜算/筹码 | **和**（伐谋为主） | 不战而屈人之兵，成本最低（谋攻） |
| 矛盾可和解 + 我筹码不足 | **待**（先为不可胜） | 先把自己做强，等筹码与时机（形） |
| 结构性对立 + 我有压倒性优势 | **战**（就事论事） | 十则围之，五则攻之（谋攻） |
| 结构性对立 + 势均力敌 | **和/待**（伐交为主） | 势均则忌硬拼，先借势借人（谋攻·军争） |
| 结构性对立 + 我明显劣势 | **走**（止损，非失败） | 小敌之坚，大敌之擒；不若则能避之（谋攻） |
| 对方正处气头上/情绪期 | **待**（避其锐气） | 避其锐气，击其惰归（军争） |

注意：主策略之外永远保留备选。"走"不是唯一解时优先"和"；"战"必须建立在"不可胜"的地基上。

## D. 升级阶梯：伐谋→伐交→伐兵→攻城

冲突处理从最高效到最低效，逐步升级。给用户方案时必须"各留一步"：先给最优，也要留退路。

| 层级 | 兵法 | 职场动作示例 | 适用 |
|---|---|---|---|
| 伐谋 | 让对方自己转变 | 做好方案让领导自己认可；把话说成"为了你的目标"；用事实让对方改变判断 | 大多数分歧 |
| 伐交 | 借势借人 | 找关键人（上级的上级、老同事、导师）牵线、背书、传话 | 直接沟通失灵时 |
| 伐兵 | 就事论事交锋 | 摆数据、讲规则、按流程对质；只谈事不伤人 | 涉及利益/责任归属 |
| 攻城 | 正面对抗 | 公开摊牌、投诉、对抗 | 最后手段，代价最大，能不用就不用 |

使用规则：每次只上一级；一级无效且伤害可控，才考虑下一级；任何时候留出"和谈"通道（兵不顿而利可全）。

## E. 四治（气、心、力、变）

军争篇治军四法，用于管理情绪与节奏：

1. **治气** — 避其锐气，击其惰归：对方状态正盛时退，疲惫松懈时进。沟通挑对方状态好的时候。
2. **治心** — 以治待乱，以静待哗：对方越乱我越稳；对方越吵我越平静。稳住就是赢。
3. **治力** — 以逸待劳：不陪跑、不内耗，保存自己的精力做关键事。
4. **治变** — 无邀正正之旗，无击堂堂之陈：对方占理又占势的时候，不要硬碰；换战场、换时间、换方式。

## F. 将有五危（自查 + 观察对方）

| 五危 | 表现 | 职场自查问题 | 对方有这毛病时怎么应对 |
|---|---|---|---|
| 必死 | 硬拼到底 | 我是不是宁可撞南墙也不回头？ | 不要和他对撞，让事实/第三方说话 |
| 必生 | 贪生怕死、只想保自己 | 我是不是因为怕得罪人就一直退让？ | 用"保他利益"的话术包装你的诉求 |
| 忿速 | 一激就怒 | 我是不是被否定就上头、秒回怼？ | 绝不激怒他；他发火时安静离场，24 小时后再说 |
| 廉洁 | 死要面子、受辱就翻脸 | 我是不是太在意评价，被激将就冲动？ | 公开给足面子，私下谈事 |
| 爱民 | 心软、被情感绑架 | 我是不是因为"不想伤人"拖垮自己？ | 少打感情牌，多谈规则与利益 |

## G. 六败（观察组织与领导）

地形篇六种败因，用于判断你的组织/领导/团队是否"有病"：

- **走**：势均力敌却硬冲 → 领导乱接活、瞎定目标
- **弛**：卒强吏弱 → 下属比主管强、指挥不动
- **陷**：吏强卒弱 → 主管太强下属跟不上、团队丧失斗志
- **崩**：大吏怒而不服 → 中层不服、各自为战
- **乱**：将弱不严、教道不明 → 没规矩、没方向、纪律涣散
- **北**：将不能料敌、以少合众 → 对市场/对手一无所知、准备不足

用法：组织/领导有上述特征且无改善迹象 → 判势向"走"倾斜；反之，环境可救则优先"和/待"。

## H. 五间职场版（信息渠道盘点）

用间篇五种情报渠道的合规转译——只用于收集信息、不做间谍行为：

| 兵法五间 | 职场版 | 示例 |
|---|---|---|
| 因间 | 就地观察与公开信息 | 看周报、会议纪要、OKR、公开评价、工作群动态 |
| 内间 | 内部人脉 | 找领导身边的同事/HR/前辈侧面了解真实意图 |
| 反间 | 反向求证 | 用"我理解你的意思是不是 X？"确认对方真实态度，辨别传言真假 |
| 死间 | 试探 | 抛出小议题/提一个试探性方案，看对方真实反应（注意：只做合规试探，不欺骗） |
| 生间 | 亲自侦察 | 直接、有准备的沟通，当面确认关键信息 |

用法：察情阶段至少点亮 3 个渠道再下结论；信息不足时，把"未知"列出来，不脑补。

## I. 常用策略组合表

按情景给出推荐组合（2–4 条兵法），使用时到 thirteen-chapters.md 取原文与动作，再按用户细节微调：

| 情景 | 推荐组合 |
|---|---|
| 领导不喜欢我/不认可我的工作方式 | 形篇"先为不可胜" + 谋攻"伐谋伐交" + 虚实"避实击虚" + 军争"避其锐气" |
| 被排挤/边缘化 | 形篇立身 + 势篇"造势"（借大项目亮相）+ 九地"静如处女动如脱兔" + 用间补信息 |
| 同事抢功/恶性竞争 | 虚实"致人而不致于人" + 谋攻"伐交"（让关键人看到）+ 火攻"合于利而动" |
| 被甩锅/背黑锅 | 行军"相敌"（先弄清事实与链条）+ 谋攻"伐兵"（就事论事摆证据）+ 慎选时机 |
| 要不要跳槽/去留 | 计篇"庙算七计" + 地形"认清地形" + 火攻"不怒而兴师"（情绪期不做决定）+ 九变"杂于利害" |
| 谈判/谈薪/争取资源 | 虚实"致人" + 谋攻"知胜有五" + 用间"先知" + 军争"以迂为直" |
| 情绪上头想爆发/裸辞 | 火攻"主不可以怒而兴师" + 九变"忿速可侮"自查 + 作战"兵贵胜不贵久"（设冷静期） |
| 项目推进受阻 | 计篇庙算（重新评估）+ 势篇"造势"（拉同盟/借资源）+ 九地"同舟共济"（找共同利益） |
