# 卡点诊断（S2）

## 技能定位

商机停滞不等于没希望，而是缺少**针对性的推进动作**。本技能按商机所处阶段和停滞证据，定位卡点类型并给出可执行动作，避免销售陷入"不知道下一步干什么"的僵局。

## 触发场景

| 触发方式 | 触发条件 |
|---|---|
| 定时触发 | 商机同阶段停留超过 N 天（默认 14 天，可按行业配置） |
| 主动调用 | 销售说"XX 这笔单卡在哪了？" |

## 输入

| 输入字段 | 来源数据表 | 说明 |
|---|---|---|
| 商机记录 | T3 销售漏斗 | 阶段、金额、停留天数 |
| 最近跟进 | T5 关系与跟进 | 最近互动时间、内容、回应情况 |
| 客户信息 | T1 客户台账 | 客户分级、关键联系人 |

## 执行步骤

1. **确认停滞**：计算同阶段停留天数，超过阈值进入诊断。
2. **按阶段初筛**：不同阶段有典型卡点（见下表），先按阶段锁定候选卡点。
3. **核对证据**：用最近跟进记录验证候选卡点（回应速度、沟通内容、接触层级）。
4. **输出诊断**：给出卡点类型、证据链、建议动作，写入商机备注。

## 阶段 × 典型卡点对照

| 商机阶段 | 最常见卡点 | 验证信号 |
|---|---|---|
| 线索 | 需求未确认 | 客户未明确预算、未进入立项讨论 |
| 需求确认 | 客户卡点 | 内部流程停滞、关键人未接触 |
| 方案报价 | 方案/价格卡点 | 方案反复修改、报价后沉默 |
| 谈判 | 价格卡点 | 竞品压价、折扣僵持 |
| 临门一脚 | 客户内部卡点 | 决策链未闭合、缺乏内部支持者 |

## 诊断输出模板

```
【卡点诊断】商机：XX｜阶段：方案报价｜停滞：23 天
- 卡点类型：价格卡点
- 证据：报价后 18 天无正式回应；竞品 A 两周前提交了折扣方案
- 建议动作：
  ① 本周内与联系人确认竞争情况（提一个开放问题，不施压）
  ② 准备价值对照表（案例 ROI + 差异化），压缩报价范围
- 若再停滞 14 天：升级管理者，评估是否继续投入
```

## 边界与红线

- 只诊断不催办：给出建议动作，是否执行由销售决定。
- 不编造证据：所有判断基于 T3/T5 真实记录，缺失数据标"待补充"。
- 停滞天数阈值可由使用者按行业调整，默认 14 天。
