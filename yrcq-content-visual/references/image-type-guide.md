# 图片类型选择指南

> 什么时候用什么图？怎么写prompt？

## 目录

- 逻辑图（AI生成）8种：因果链/对比/步骤/思维导图/架构/时间线/矩阵/流程
- 概念图（找官方现成的）5种：大模型/RAG/Agent/Skill-MCP/知识库
- 选择速查表：一句话判断用什么图

---

## 逻辑图（AI生成）8种

### 1. 因果链流程图
**什么时候用**：讲"为什么会XX""XX是怎么造成的"
**例子**：大模型为什么会胡说八道？

**prompt模板**：
```
[风格]风格的因果链流程图，竖版3:4比例，标题"[标题]"。
中间是从上到下的因果链，[N]个方框用箭头连接：
第一个方框[颜色1]背景："[第一步标题]"，下面小字"[第一步说明]"
第二个方框[颜色2]背景："[第二步标题]"，下面小字"[第二步说明]"
...
底部一句话总结："[总结]"
配色：主色#[色值1]，辅助色#[色值2]，强调色#[色值3]，背景白色。
文字清晰可读，排版整齐。
```

---

### 2. 左右对比图
**什么时候用**：讲"你以为的 vs 实际上是""A和B的区别"
**例子**：大模型是查数据库还是猜下一个词？

**prompt模板**：
```
[风格]风格的左右对比图，竖版3:4比例，标题"[标题]"。
中间左右分栏对比：
左边[颜色1]背景，标题"[左栏标题]"，下面写"[左栏内容]"，配[图标1]
右边[颜色2]背景，标题"[右栏标题]"，下面写"[右栏内容]"，配[图标2]
底部一句话总结："[总结]"
配色：主色#[色值1]，强调色#[色值2]，背景白色。
文字清晰可读，左右对称。
```

---

### 3. 步骤/方法图
**什么时候用**：讲"怎么做""X个方法""X个步骤"
**例子**：3个方法治AI胡说八道

**prompt模板**：
```
[风格]风格的步骤图，竖版3:4比例，标题"[标题]"。
中间从上到下排列[N]个步骤：
第一步：[颜色1]圆形图标，标题"1. [步骤1标题]"，小字"[步骤1说明]"
第二步：[颜色2]圆形图标，标题"2. [步骤2标题]"，小字"[步骤2说明]"
...
底部一句话总结："[总结]"
配色：主色#[色值1]，辅助色#[色值2]，强调色#[色值3]，背景白色。
文字清晰可读，步骤分明。
```

---

### 4. 思维导图
**什么时候用**：讲"一个主题有几个分支""XX包含哪些部分"
**例子**：知识星球的6大内容板块

**prompt模板**：
```
[风格]风格的思维导图，横版4:3比例，中心主题"[中心主题]"。
中间是中心节点，向外发散[N]个分支：
分支1：[颜色1]，标题"[分支1标题]"，下面2-3个小点
分支2：[颜色2]，标题"[分支2标题]"，下面2-3个小点
...
配色：主色#[色值1]，辅助色#[色值2]，强调色#[色值3]，背景白色。
文字清晰可读，结构清晰。
```

---

### 5. 架构图
**什么时候用**：讲"一个系统有几层""一个产品的组成部分"
**例子**：我们的内容体系结构

**prompt模板**：
```
[风格]风格的架构图，横版4:3比例，标题"[标题]"。
中间是分层架构，从上到下[N]层：
第一层：[颜色1]背景，"[第一层名称]"，下面写"[第一层包含什么]"
第二层：[颜色2]背景，"[第二层名称]"，下面写"[第二层包含什么]"
...
配色：主色#[色值1]，辅助色#[色值2]，强调色#[色值3]，背景白色。
文字清晰可读，层级分明。
```

---

### 6. 时间线
**什么时候用**：讲"发展过程""从X到Y的路径"
**例子**：从认知到应用的学习路径

**prompt模板**：
```
[风格]风格的时间线，横版4:3比例，标题"[标题]"。
中间是横向时间线，[N]个节点从左到右排列：
节点1：时间"[时间1]"，标题"[阶段1]"，说明"[阶段1说明]"
节点2：时间"[时间2]"，标题"[阶段2]"，说明"[阶段2说明]"
...
配色：主色#[色值1]，辅助色#[色值2]，强调色#[色值3]，背景白色。
文字清晰可读，时间顺序明确。
```

---

### 7. 矩阵图
**什么时候用**：讲"两个维度分类""四象限"
**例子**：用户分层：按活跃度和付费意愿分

**prompt模板**：
```
[风格]风格的四象限矩阵图，横版4:3比例，标题"[标题]"。
中间是2x2四象限：
X轴：[X轴名称]，从左到右[X轴说明]
Y轴：[Y轴名称]，从下到上[Y轴说明]
第一象限（右上）：[象限1名称]，说明"[象限1说明]"
第二象限（左上）：[象限2名称]，说明"[象限2说明]"
第三象限（左下）：[象限3名称]，说明"[象限3说明]"
第四象限（右下）：[象限4名称]，说明"[象限4说明]"
配色：主色#[色值1]，辅助色#[色值2]，强调色#[色值3]，背景白色。
文字清晰可读，象限分明。
```

---

### 8. 流程图
**什么时候用**：讲"一个流程怎么走""第一步做什么第二步做什么"
**例子**：从选题到发布的工作流

**prompt模板**：
```
[风格]风格的流程图，竖版3:4比例，标题"[标题]"。
中间是从上到下的流程图，[N]个步骤用箭头连接：
步骤1：[颜色1]方框，"[步骤1]"
步骤2：[颜色2]方框，"[步骤2]"
...
步骤N：[颜色3]方框，"[步骤N]"
配色：主色#[色值1]，辅助色#[色值2]，强调色#[色值3]，背景白色。
文字清晰可读，流程明确。
```

## 选择速查表

| 文章在讲什么 | 用什么图 |
|-------------|---------|
| 为什么会XX | 因果链流程图 |
| A和B有什么区别 | 左右对比图 |
| 怎么做/几个方法 | 步骤/方法图 |
| XX包含哪些部分 | 思维导图 |
| XX系统有几层 | 架构图 |
| 从X到Y的过程 | 时间线 |
| 两个维度分类 | 矩阵图 |
| 一个流程怎么走 | 流程图 |
| 技术概念（大模型/RAG等） | 找官方现成的 |
