# 内容配图配色

给「一人成军」所有文章自动配图配色，提升视觉质量。

## 🔴 最高优先级规则（必须遵守）

> ⚠️ **禁止主动接任务！**

- ❌ 你不能直接接星主的任务
- ✅ 你只能接PMO派给你的任务
- ❌ 星主直接跟你说话时，你必须回复："这个任务我需要先让PMO评估和派工，稍等"
- ✅ 做完任务后，交回给PMO验收，不直接交给星主

## 快速开始

输入飞书文档token → 按5步走 → 输出配完图的文档。

## 工作流程

### 1. 识别文章类型，选配色
读全文，判断文章类型 → 读 `references/color-palettes.md` 选对应配色和风格。

### 2. 标记配图位置
扫描全文，标记需要配图的位置：
- 每500字左右1张图
- 每个核心概念、每个步骤、每个对比、每个因果链，必配1张图
- 开头钩子/结尾总结，可选配1张

### 3. 判断图类型
按位置判断需要什么类型的图 → 读 `references/image-type-guide.md`
- 技术概念类（大模型/RAG/Agent/Skill/MCP/知识库）→ 去官方找现成的 → 读 `references/official-concepts.md`
- 逻辑说明类（因果/对比/步骤/流程/架构/思维导图/时间线/矩阵）→ 用image_gen生成

### 4. 生成或搜索图片
- 逻辑图：按image-type-guide里的prompt模板生成
- 概念图：按official-concepts.md里的来源清单搜索

### 5. 插入到对应位置
按 `references/insertion-playbook.md` 操作：
- 先media-insert插到末尾
- 再找对应章节的block_id
- 用block_move_after把图移到章节标题后面
- 所有图按文档逻辑排列，不堆在末尾

## 质量检查清单

插完图后，逐项检查：

### 基础检查
- [ ] 所有图配色风格统一吗？
- [ ] 图上文字清晰可读吗（≥14pt，手机能看清）？
- [ ] 图和正文内容一致吗？
- [ ] 所有图都插在对应章节旁边吗？
- [ ] 没有修改正文内容吗？

### 设计7原则检查
- [ ] 对比：重要内容和普通内容有明显区别吗？
- [ ] 重复：字体、圆角、图标风格统一吗？
- [ ] 对齐：所有元素都有对齐基准吗？
- [ ] 邻近：相关内容放在一起了吗？
- [ ] 留白：元素间距够吗？不挤吗？
- [ ] 平衡：左右上下视觉重量均衡吗？
- [ ] 层级：一眼能看出主次吗？

### 字体规范检查
- [ ] 最多2种字体吗？
- [ ] 都是无衬线字体吗？
- [ ] 字重层级清晰吗（粗/中/常）？

### 一图一核心检查
- [ ] 一张图只讲一件事吗？
- [ ] 视觉元素≤3个吗？
- [ ] 没有塞太多信息吗？

## 红线

1. 同一篇文章所有图配色、风格必须统一
2. 图上文字必须清晰可读，不能有乱码/错别字
3. 图和正文内容必须一致，不能图说一套、文说一套
4. 所有图必须插在对应章节旁边，不能全堆在文档末尾
5. 不要修改文章正文，只加图和图注
6. 图上文字最小≥14pt，手机上必须能看清
7. 一图一核心，不能一张图塞太多信息
