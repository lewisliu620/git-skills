# 赢率预估（S5）

## 技能定位

赢率不是拍脑袋的数字，而是**可校准的区间**。本技能给出基础赢率，再用客户、关系、竞争三类系数修正，最后输出针对短板的提赢动作——让"提赢"有具体抓手。

## 触发场景

| 触发方式 | 触发条件 |
|---|---|
| 主动调用 | 商机进入方案报价阶段时，或销售问"XX 这单赢率多少？" |

## 输入

| 输入字段 | 来源数据表 | 说明 |
|---|---|---|
| 商机阶段 | T3 销售漏斗 | 决定基础赢率 |
| 客户分级 | T1 客户台账 | 战略性/重点/一般 |
| 健康分 | T3（S1 输出） | 商机健康度 |
| 关系深度 | T5 关系与跟进 | 认识/熟悉/信任/依赖 |
| 竞争态势 | 录入信息 | 对手数量与强度 |

## 执行步骤

1. **取基础赢率**：按阶段查下表。
2. **系数修正**：客户分级、健康分、关系深度、竞争四类系数相乘。
3. **输出区间**：修正值 ±8% 为区间（上限不超 95%）。
4. **短板提赢**：取四项系数中最低的 1-2 项，输出对应提赢动作。

## 基础赢率（按阶段）

| 商机阶段 | 基础赢率 |
|---|---|
| 线索 | 15% |
| 需求确认 | 30% |
| 方案报价 | 45% |
| 谈判 | 60% |
| 临门一脚 | 75% |

**修正系数**：客户分级（战略性 1.15 / 重点 1.0 / 一般 0.85）；健康分（≥75 → 1.1，50-74 → 1.0，<50 → 0.8）；关系深度（依赖 1.15 / 信任 1.05 / 熟悉 0.95 / 认识 0.8）；竞争（独家 1.2 / 2-3 家 1.0 / 强对手 0.85）。

## 提赢动作（按短板匹配）

| 短板项 | 提赢动作 |
|---|---|
| 关系深度不足 | 安排决策链关键人接触，找教练获取内部信息 |
| 健康分偏低 | 先按 S1 体检卡处理卡点，再谈赢率 |
| 竞争压力大 | 输出差异化价值对照表，强化成功案例背书 |
| 客户分级低 | 评估投入产出，控制投标成本与时间投入 |

## 输出模板

```
【赢率预估】商机：XX｜阶段：方案报价
基础赢率 45% × 客户分级 1.15 × 健康分 1.0 × 关系 1.05 × 竞争 1.0 = 54%
预估区间：46% - 62%
短板提赢：关系深度（信任）→ 两周内约见决策人，带上制造业案例
```

## 边界与红线

- 赢率是参考区间，不是承诺；不输出"必赢/必输"结论。
- 基础赢率为通用经验值，使用者可按自身行业历史数据校准。
- 数据缺失（如竞争态势未记录）时按 1.0 处理并标注。
