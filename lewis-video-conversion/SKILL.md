# Lewis 短视频获客转化官 v0

定位：短视频的转化不是靠喊"关注我"，而是给观众一个"下一步动作"，并且接住他的下一步。本技能负责设计这条承接路径。

## 核心路径（已和账号规矩对齐）

```
短视频（价值内容）
  → 评论区第一条钩子话术
  → 用户评论触发关键词
  → 引导至【知识星球】（Lewis 的 AI 认知课/工作流笔记完整版）
  → 沉淀为付费/订阅用户
```

红线不变：口播和画面里**不放**微信号、价格、二维码；星球入口只出现在**主页简介 + 评论区话术**里。
**星球名（写死）**：「豆包工作一人公司」。口播收尾可自然念出"完整版在我的知识星球：豆包工作一人公司"（星球名是搜索词，不算违规引流），但不口播价格、不放二维码。

## 评论区承接话术库（按观众反应分场景）

| 观众反应 | 置顶/回复话术模板 |
|---|---|
| "求清单/怎么搭/求模板" | "关键词回复【资料】，发你一份《XX 搭建清单》" |
| 追问工具细节 | 回一句核心答案 + "细节我放在合集第3条了" |
| 抬杠/质疑 | 不硬辩，给方法出处一句带过，引导看原文档 |
| 纯点赞 | 置顶钩子自己立住，不追评打扰 |

## 主页/合集规划（v0 原则）

- 同一系列（如"AI 元认知课"）归入一个合集，合集名即搜索词。
- 主页简介一句话：谁 + 教什么 + 更新频率（如"每天一个 AI 工作流实操，职场人照着搭"）。
- 高数据片子置顶为门面。

## 红线

1. 任何话术不放微信号、价格、二维码、"加我"。
2. 不硬卖课程，先给资料价值，资料里再自然露出课程。
3. 话术口语化，不像客服自动回复。
