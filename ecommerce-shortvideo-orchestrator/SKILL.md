# 电商商品短视频编排器

本 Skill 是编排器：负责从素材到成片的完整流程，在脚本和粗剪两个节点强制停点给用户确认。
创造性工作（卖点/钩子/脚本/节奏判断）由 LLM 直接完成，事务性工作（裁剪/拼接/字幕/导出）走 ffmpeg。

## 快速开始

收集素材 → 卖点提炼 → 钩子A/B 3版 → 分镜脚本 → **停点1：脚本确认** → 素材预处理 → 缺镜头AI补 → 配音 → 粗剪 → **停点2：粗剪确认** → 精剪+合规 → 3版本导出。

## 前置检查

开工前先确认素材：
- 商品图片 ≥3 张？（白底图/场景图/细节图）
- 商品详情文案有吗？
- 图片分辨率 ≥1080px？不够就告诉用户换素材
- 缺什么直接问，不硬凑

---

## 工作流

### 第一步：卖点提炼（纯 LLM，不调 Skill）

读取商品详情文案，输出：
```
核心卖点（≤15字，说好处不说参数，按重要性排序）：
1. _____
2. _____
3. _____

核心痛点（具体场景，不说形容词）：
_____

一句话核心卖点：这款XX能帮你解决XX问题。
```

### 第二步：钩子设计 A/B 3 版本（纯 LLM）

生成 3 个不同风格的前 2-3 秒口播钩子：

| 类型 | 套路 | 示例 |
|---|---|---|
| 痛点型 | 喊出目标用户的具体烦恼 | "还在为____烦恼？" |
| 反差型 | 否定常见做法 | "别再乱买____了！" |
| 利益型 | 直接给好处/数字 | "这个____只要____！" |

要求：每个 ≤10 字，前 2 秒抛出，不报品牌名。

### 第三步：分镜脚本（纯 LLM，7 列表格）

按 25 秒四段式输出：

| 镜号 | 时长 | 画面内容 | 用什么素材 | 口播文案 | 字幕文案 | 运镜 |
|---|---|---|---|---|---|---|
| 1 | 0-2s | 痛点场景 | 场景图 | （钩子） | 同口播 | 快速推近 |
| 2 | 2-5s | 产品亮相 | 白底图 | _____ | _____ | 缓慢推近 |
| 3 | 5-12s | 使用场景 | 商品视频片段 | _____ | _____ | 原速/慢放 |
| 4 | 12-18s | 细节/对比 | 细节图+视频 | _____ | _____ | 特写推近 |
| 5 | 18-25s | CTA | 白底图 | "点击下方链接" | 同口播 | 静止 |

要求：
- 每 2-3 秒一个镜头切换
- 口播句子 4-12 字，口语化
- 每个镜头明确标注素材来源（哪张图/哪段视频第几秒）
- 一个视频只打 1 个核心卖点

---

### ⛔ 停点 1：脚本确认

把以下内容给用户看，等确认后再继续：
1. 3 个候选钩子
2. 完整分镜表
3. 哪些镜头缺素材需要 AI 补

用户说"OK/继续"才往下走。

---

### 第四步：素材预处理

**图片（ffmpeg）：**
```bash
ffmpeg -i input.jpg -vf "scale=1080:1920:force_original_aspect_ratio=decrease,pad=1080:1920:(ow-iw)/2:(oh-ih)/2:color=#f5f5f5" output.jpg
```
- 扩图加背景，不裁剪产品
- 统一亮度对比度

**视频片段：**
- 长视频（>10秒）：用 byted-mediakit-video 提取高光时刻
- 短视频：ffmpeg 裁竖版
```bash
ffmpeg -i input.mp4 -vf "crop='min(iw,ih*9/16)':'min(ih,iw*16/9)',scale=1080:1920" -ss START -t DURATION output.mp4
```

### 第五步：缺镜头 AI 补生成

原则：实拍素材能解决的不用 AI。只有脚本要求但用户没素材的镜头才补。
- 用 doubao-creative-video / seedance-25
- 提示词按 seedance-real-selling-video 方法论写（三段锁定+负面轰炸）

### 第六步：配音（seed-audio）

一次生成复合音频：
```
XX岁男性/女性，普通话，亲切像朋友推荐，语速稍快。
口播："（完整口播稿）"
BGM：轻快有节奏，音量低，不抢人声。
```

### 第七步：粗剪拼接（ffmpeg）

按分镜表顺序拼接所有素材。图片加 Ken Burns 动效：
```bash
ffmpeg -loop 1 -i img.jpg -vf "zoompan=z='min(zoom+0.001,1.1)':d=150:s=1080x1920:fps=30" -t 5 output.mp4
```
先不加字幕，看整体节奏。

---

### ⛔ 停点 2：粗剪确认

给用户看粗剪版，问：节奏对不对？素材选得对不对？产品清不清楚？
用户通过才精剪。

---

### 第八步：精剪 + 合规

**ffmpeg 精剪：**
```bash
ffmpeg -i rough.mp4 -i voice_bgm.mp3 \
  -vf "subtitles=subs.srt:force_style='FontSize=22,PrimaryColour=&HFFFFFF&,OutlineColour=&H000000&,Outline=2,Alignment=2,MarginV=80'" \
  -c:v libx264 -c:a aac -shortest final.mp4
```
- 全程字幕，底部安全区内
- BGM 音量压到人声 25%
- 统一调色：`eq=saturation=0.9:contrast=1.05,noise=alls=8:allf=t`

**合规自查（普通品类内置规则）：**
- ❌ 最/第一/顶级/国家级
- ❌ 包治/100%见效/永不反弹
- ❌ 虚构原价/虚假折扣
- ❌ 食品宣称疗效
- 强监管品类（医疗/金融/母婴）才调 doubao-marketing-material-review

### 第九步：3 版本导出

同一个主体视频，只换前 2-3 秒开头：
- 版本 A：痛点型钩子
- 版本 B：反差型钩子
- 版本 C：利益型钩子

后面 18 秒素材拼接不变，只重新剪开头再拼上。导出 3 个独立 MP4。

## 质量检查清单（交付前必过）

- [ ] 前 2 秒有钩子？
- [ ] 总时长 20-30 秒？
- [ ] 全程字幕（静音能看懂）？
- [ ] 每 2-3 秒画面变化？
- [ ] 无违规词？
- [ ] 产品展示清晰不变形？
- [ ] 有明确 CTA？
- [ ] 3 个钩子版本都导出？
- [ ] 1080×1920 MP4/H.264？

## 不做什么

- ❌ 不做 AI 真人出镜口播
- ❌ 不做商品详情页图
- ❌ 不批量生成
- ❌ 不做转场特效（MVP 硬切）
- ❌ 不自动重试（翻车即停，给用户看）
