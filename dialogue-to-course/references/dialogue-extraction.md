# 对话提取指南

> 怎么从对话历史里，提取出有用的内容做成课程？

---

## 输入形式

用户通常会这样说：

1. **按范围**："从'先优化我的提示词...'开始，到'✅ 搭建完成'为止"
2. **按主题**："把刚才做prompt-optimizer的过程做成课程"
3. **按轮次**："从第1轮到第10轮"

---

## 提取步骤

### Step 1：定位起点和终点

在对话历史里，找到用户说的起点那句话和终点那句话。

如果找不到：
- 模糊匹配关键词
- 还是找不到就问用户

### Step 2：拆解阶段

把整个对话过程，按"需求变化"拆解成几个阶段：

| 阶段类型 | 特征 |
|----------|------|
| 提需求 | 用户第一次说要做什么 |
| 第一版 | AI出第一版结果 |
| 加功能 | 用户说"再增加XX" |
| 发现问题 | 用户说"不对，XX有问题" |
| 修复 | AI改完了 |
| 最终完成 | 用户说"确认" |

### Step 3：每阶段选一轮

**原则**：同一阶段只取最有代表性的一轮对话。

不要把所有对话都放进去，那样太啰嗦。

**选哪一轮？**
- 最能代表这个阶段的核心问题的
- 最有"啊，原来如此"感觉的
- 对话不长不短，刚好能说清楚问题的

### Step 4：整理成对话记录

每个阶段的格式：

```
阶段N：标题

你说：
（用户的原话，放在代码块里）

AI回复：
（AI的原话，放在代码块里）

阶段总结：改了什么，解决了什么问题
```

---

## 常见情况处理

### 情况1：对话太长，几十轮

**处理**：
- 不要全取，按阶段提炼
- 每个阶段取最有代表性的1轮
- 中间很多重复的、差不多的对话，跳过

### 情况2：对话太短，只有几轮

**处理**：
- 直接全放进去
- 不用删减
- 补充一些总结性内容，让课程看起来丰满

### 情况3：对话中间夹着很多工具调用

**处理**：
- 工具调用不用放到课程里
- 只保留"用户说什么 + AI回复什么"的对话部分
- 工具调用是后台的事，用户看不到

### 情况4：有很多试错的过程

**处理**：
- 试错的过程是好内容！
- 这就是"踩坑"部分的素材
- 不要跳过，要放到第三部分"真实踩坑"里

---

## 提取后的检查清单

- [ ] 有没有遗漏关键阶段？
- [ ] 每个阶段是不是只取了1轮？
- [ ] 对话记录是不是真实的原话？
- [ ] 有没有把工具调用放进去？（不要）
- [ ] 有没有脱敏？

---

## 例子

**用户说**：
> 从"先优化我的提示词：在我说完内容后，我要在所有的生成前加上一个提示词优化skill"开始，到"✅ 通用提示词优化Skill 已搭建完成"为止

**你做**：
1. 在对话历史里找到这两句话
2. 中间的对话拆解成7个阶段：提需求→加框架→改通用→定触发→发现问题1→发现问题2→发现问题3
3. 每个阶段取1轮对话
4. 整理成课程第二部分
